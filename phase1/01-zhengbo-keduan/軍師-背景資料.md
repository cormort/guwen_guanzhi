# 〈鄭伯克段于鄢〉背景資料

---

## 一、座標定位

| 項目 | 內容 |
|------|------|
| **出處** | 《左傳·隱公元年》 |
| **作者** | 左丘明（春秋魯國史官，生卒不詳，約與孔子同時代） |
| **事件年份** | 魯隱公元年，西元前 **722 年**（《春秋》記事之始年；鄭國方面為鄭莊公二十二年） |
| **體裁** | 編年體史書，以魯國國君年號繫事 |
| **篇幅地位** | 《古文觀止》卷一·周文首篇，最經典的春秋敘事典範 |
| **一句話總結** | 鄭莊公長期縱容其弟共叔段的野心，待其舉兵才一舉擊潰，演出了春秋初期最著名的欲擒故縱權謀 |

> 左丘明作《左傳》，後世譽為「敘事之宗」。此篇乃其代表作，也是後世古文家必讀的入門篇章。

---

## 二、時代背景：春秋初期的戰略棋盤

### 周室衰微，禮崩樂壞

- 西元前 **770 年**，周平王東遷洛邑，西周結束，東周（春秋）開始。自此「禮樂征伐自天子出」變成「自諸侯出」。
- 天子的權威僅剩名義，諸侯實質獨立，弱肉強食成為新常態。
- 本篇事發於西元前 722 年，距東遷僅約 48 年——周室的威望還在，但已壓不住諸侯。

### 鄭國最早崛起

- 鄭是周宣王在西元前 **806 年**分封的姬姓諸侯，始封君鄭桓公是周王室近親。
- 鄭桓公（為周幽王司徒）、鄭武公、鄭莊公三代先後在周室任職（武公、莊公為周平王卿士）。鄭莊公同時是鄭國國君與周朝卿士，這是鄭國能在春秋初期率先稱強的重要原因。
- 鄭莊公時代，鄭國軍事力量冠絕中原；但他把這份力量主要用在對內。本篇之後，鄭國仍有共叔段之子公孫滑奔衛、衛人為之伐鄭取廩延的餘波（《左傳》同年下文），內亂並未隨段出奔而立刻結束。

### 時代主題詞

> **「王室衰微 → 大國崛起 → 內部權力鬥爭 → 外部兼併戰爭」**
>
> 鄭伯克段正是此一權力鬥爭循環的開端與典型案例。

## 三、關鍵人物解碼

### 鄭莊公（約西元前 757–701 年）—— 隱忍算計型領袖

| 面向 | 解析 |
|------|------|
| **性格** | 隱忍、深沉、精於算計。不怒不躁，但每一步都有伏筆。 |
| **對弟策略** | 明知共叔段有異心，卻故意放任其壯大——「多行不義必自斃，子姑待之。」（經典名言） |
| **軍事決斷** | 一出手就是斬首行動：命子封率 **200 乘戰車**伐京，京邑叛段，段逃至鄢，莊公再伐鄢，段終出奔共國。 |
| **政治智慧** | 克段後對母親武姜發誓「不及黃泉，無相見也」，旋即後悔。潁考叔藉進獻食物之機，故意捨肉留給母親，點醒莊公；莊公坦言後悔後，潁考叔順水推舟獻計「闕地及泉，隧而相見」，既不失孝名、又不違誓言，替莊公解開了輿論死結。 |
| **軍師評價** | **春秋初期第一流的權謀君主**。其忍功之深、出手之準、收尾之漂亮，可為權謀家的教科書案例。 |

> 生卒年說明：鄭莊公生年（前 757）與卒年（前 701，魯桓公十一年）為後世推定的通行說法；《左傳》本身未載其生年。在位自西元前 743 年（鄭武公卒）至前 701 年，約 43 年。

### 共叔段 —— 被寵壞的弟弟

| 面向 | 解析 |
|------|------|
| **出身** | 鄭武公之子、莊公之弟（同母弟）。其兄莊公出生時為逆產（寤生），母親武姜因此厭惡莊公、偏愛段。 |
| **個性** | 恃寵而驕、貪得無厭。先封京邑，後擴張至西鄙、北鄙，再修城聚糧、整治甲兵。 |
| **致命錯誤** | 嚴重低估哥哥的忍耐力與手段。認為莊公不敢動他，結果一動便是兵敗流亡。 |
| **結局** | 兵敗出奔**共國**（今河南輝縣），此後不再出現於鄭國政壇。 |
| **軍師評價** | 典型的「資源過剩、教養不足」案例。有野心無戰略，有資源無耐心，結局早已注定。 |

### 武姜 —— 偏心的母親

| 面向 | 解析 |
|------|------|
| **地位** | 申國女子，鄭武公夫人，莊公與共叔段之母。 |
| **偏愛源頭** | 生莊公時是逆產（寤生），因而厭惡長子、偏愛幼子。（「寤生」舊注多解為難產，另有「睡夢中驚醒而生」等異說，非定論。） |
| **具體行動** | 屢次向鄭武公請求立段為太子（未遂）；莊公即位後又為段請求封地（先求制邑、後得京邑）；最後甚至打算在段舉兵時為內應開城門。 |
| **結局** | 段敗後被莊公置於城潁，莊公發誓「不及黃泉，無相見也」，不久後由潁考叔藉「捨肉遺母」點醒莊公，設計闕地及泉，遂隧而相見。 |
| **軍師評價** | 情感用事、公私不分，以偏愛之私動搖國本。武姜之誤，誤在「以母愛之名行害國之實」。 |

### 祭仲（祭足）—— 忠直老臣

| 面向 | 解析 |
|------|------|
| **角色定位** | 鄭國大夫，莊公倚重的重臣。 |
| **關鍵諫言** | 最早向莊公示警：「姜氏何厭之有？不如早為之所，無使滋蔓。蔓，難圖也。」（經典段子：「蔓草猶不可除，況君之寵弟乎？」） |
| **性格** | 直諫、顧大局、有遠見。深知共叔段必成後患。 |
| **命運** | 祭仲在鄭國政壇活躍數十年，日後莊公死後還一度執政鄭國。 |
| **軍師評價** | 標準的「忠臣先知」——預見災難、及時進諫。但莊公不採，因為莊公要的不是「防患於未然」，而是「待其成罪而討之」。 |

### 潁考叔 —— 全篇的道德出口

| 面向 | 解析 |
|------|------|
| **角色定位** | 鄭國大夫，時任潁谷（今河南登封一帶）掌封疆之官。 |
| **關鍵動作** | 「食舍肉」——吃飯時把肉留下，以「小人有母，皆嘗小人之食矣，未嘗君之羹」觸動莊公；再獻「闕地及泉，隧而相見」，替莊公解開「不及黃泉，無相見也」的死結。 |
| **軍師評價** | 全篇唯一不為權力而動作的人。左氏以「純孝」二字收束全篇，正是要用他對照莊公的算計——莊公贏了弟弟，卻得靠一個小官的孝心才換回母親。 |

## 四、寫作意圖：左傳為何記錄這件事？

### 1. 示範「以禮法為刀」的政治操作

莊公明知弟欲叛，卻不先打壓，反而：

- 放任段擴張領地（京邑→西鄙北鄙→廩延）
- 等段真正舉兵時，才以「叛國」名義雷霆出擊

這在當時禮法框架下是**精心計算的政治操作**：不動手時占著「兄友弟恭」的道德位置，一動手則占著「討逆」的名分。左氏在篇末評註裡說得很直白：「莊公養成弟惡，故曰失教」——縱容本身就是責任，所以《春秋》要譏他「失教」。

> 左丘明極少直接議論，主要透過敘事與「春秋筆法」讓後世自行評判，僅在結尾借「君子曰」引《詩》輕輕一點。這就是《左傳》最厲害的地方。

### 2. 提供「兄弟相殘」的經典敘事模板

春秋時代，諸侯國內部的嫡庶之爭、兄弟相殘是家常便飯。左傳記錄此案，為後世提供了一個完整的案例：

- 母親偏心 → 弟弟野心膨脹 → 哥哥故意縱容 → 一舉擊潰
- 此後兩千多年，史書中類似劇本反覆上演。

### 3. 與孔子《春秋》經文互為經緯

《春秋》經文：「夏五月，鄭伯克段于鄢。」《左傳》則以五百餘字把此事展開為完整的起承轉合。

- 《春秋》是綱（大事記）
- 《左傳》是目（詳細報導）

讀者對照經傳，方能明白「克」字為何帶貶義——兄弟相爭本該用「奔」「逐」一類的字，卻用敵對國君交戰的「克」，意在譏刺鄭莊公失教於弟、處心積慮以成殺弟之事。同時經文稱「鄭伯」而非「公」，亦是貶其失教；稱「段」而非「弟」，則兼責共叔段不守弟道。

### 4. 一句六字，讀者要自己判斷

「鄭伯克段于鄢」六個字裡，左氏拆出四層評價（不稱弟、用克、稱鄭伯、不言出奔），卻始終沒有說「莊公是壞人」。他把判斷的責任交給讀者——這也是《古文觀止》把它放在全書第一篇的原因：讀古文，先學會讀出字縫裡的東西。

---

## 五、一句話總結

> **鄭莊公長期縱容其弟共叔段的野心，待其舉兵才一舉擊潰，段出奔共國；莊公雖贏了權力，卻因「不及黃泉，無相見也」的誓言幾乎失去母親，最後靠潁考叔的一計挽回——左丘明用六個字的經文與五百餘字的敘事，把這場骨肉相殘寫成了中國歷史開篇最冷靜的一課。**

---

*軍師批語：當你覺得敵人太弱、可以慢慢玩的時候，先想想共叔段。當你覺得忍耐太久、想提早攤牌的時候，再想想鄭莊公。*
