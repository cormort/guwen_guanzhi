# 〈遊褒禪山記〉背景資料

> **風格**：軍師推演 · **體裁**：說理遊記 · **編次**：《古文觀止》卷十一·宋文

---

## 一、座標定位

| 項目 | 內容 |
|------|------|
| **時間** | 北宋·仁宗至和元年（1054）七月 |
| **作者** | 王安石（1021–1086），字介甫，號半山，臨川人 |
| **官職** | 時任舒州通判（時年三十三歲） |
| **地點** | 安徽含山縣北·褒禪山（今稱褒山或華陽山） |
| **地理意義** | 長江沿岸丘陵地貌，多石灰岩溶洞，正合文中「有穴窈然」之景 |

### 更精確的時局標定

至和元年（1054）七月，王安石三十三歲，任舒州通判。此時仁宗在位已三十餘年，天下承平日久，但官僚冗濫、財政空虛、邊患叢生——北宋的「積貧積弱」已經全面發作。

王安石本人正處於仕途上升期，尚未進入權力中樞，但其變法思想已在地方施政中不斷試煉。舒州任上他推行青苗法雛形（貸糧於民、秋收償還），成效顯著。這篇文章表面上寫一次失敗的洞穴探險，實質上是他政治哲學的第一次完整書面陳述——比〈上仁宗皇帝言事書〉（1058）早了四年。

---

## 二、時代壓力：變法前夜的醞釀與掙扎

**北宋中葉三大病灶：**

1. **三冗危機**——冗官、冗兵、冗費。宗室恩蔭、科舉取士逐年膨脹，禁軍達百四十萬而戰鬥力空虛，養兵養官的開銷佔財政收入十分之七八。
2. **邊防困局**——西夏元昊稱帝（1038）後連年交戰，宋軍屢敗。慶曆四年（1044）簽訂「慶曆和議」，歲賜絹十三萬匹、銀五萬兩、茶二萬斤，連同節慶賞賜合約二十五萬五千，換來名義上的稱臣，實則屈辱。
3. **慶曆新政失敗**——范仲淹在仁宗支持下推行「慶曆新政」（1043），不到兩年即因保守派反撲而廢止。改革派的信譽與動能遭到重挫，朝中瀰漫「多一事不如少一事」的姑息之氣。

**王安石在此時的心境：**

他親眼見證范仲淹的失敗，深知改革之難不在於「方案對不對」，而在於「人能不能堅持」。褒禪山之遊中，那個舉火入洞、卻半途喊停的同行者，正是他對改革同僚最深刻的隱喻——你們明明有火把（資源）、有志願（初心），為什麼不再多走幾步？差的就是那一點「盡吾志也而不能至者，可以無悔矣」的決絕。

> 這是王安石對自己、也是對未來所有變法志士的告誡：**不是做不到，是走不到底。**

## 三、關鍵人物

### 核心人物：王安石（自述者）

- 三十三歲，思想已經成熟，行事風格日趨峻厲
- 舒州任上的施政經驗讓他堅信「變法可救天下」，但同時也讓他看清人性的弱點——支持改革的人，往往在壓力面前第一個退縮
- 文中以「予」自稱，語氣冷靜、理性，帶有克制的不甘

### 同遊四人（文末具名）

| 人物 | 身份 | 在文中的角色 |
|------|------|-------------|
| **蕭君圭（字君玉）** | 廬陵人，王安石友人 | 僅記名，未述其行 |
| **王回（字深父）** | 長樂人，學者型人物 | 僅記名，未述其行 |
| **王安國（字平父）** | 王安石之弟 | 僅記名，未述其行 |
| **王安上（字純父）** | 王安石之弟 | 僅記名，未述其行 |

> 校勘註：四人皆見於文末「四人者：廬陵蕭君圭君玉，長樂王回深父，予弟安國平父、安上純父」。坊間有版本誤作「蕭珪」，或將第四人誤傳為「僧人導遊」，皆非通行本原貌——四人中並無僧人。

### 軍師視角的關鍵洞察：那個「欲出者」是誰？

很多人讀此文只注意「志、力、物」的哲學三段論，但忽略了一個細節——

> 既其出，則或咎其欲出者，而予亦悔其隨之，而不得極乎遊之樂也。

文中只以「有怠而欲出者」稱之——「一個倦怠想退出的人」，始終沒有指名道姓：他不是僧人、不是導遊，也不是四人中特定的哪一位。更關鍵的是，他喊停的理由「火且盡」其實並不成立——下文明言「方是時，予之力尚足以入，火尚足以明也」。也就是說，這次半途而廢不是資源真的耗盡，而是有人先動搖了。這和變法完全一樣：**最先喊「不行了」的人，往往不是沒有資源，而是信心先垮；他一退，整群人就跟著退。**

王安石隱隱點出：慶曆新政失敗，不是因為方案不對，而是因為范仲淹身邊的關鍵人物（或是仁宗本人）先動搖了。

## 四、寫作意圖：以遊山喻改革，以洞穴喻天下

### 表層結構：一次失敗的探險

一群人興致勃勃要去探洞，走了沒多遠，有人倦怠想退出，說「不出，火且盡」，於是全軍撤退。出來後大家互相埋怨，但王安石最終把檢討的矛頭指向自己——「悔其隨之」。他不是怪那個提議退出的人，而是怪**自己為什麼不堅持一下、說服大家繼續走**。

### 深層結構：變法的條件論

文中「於是予有嘆焉」一段才是正文的核心。三層邏輯：

```
至極之境  ───┬── 志（決心）    ──→ 沒有志願，一步都走不了
             ├── 力（能力、毅力）──→ 有志還要能走，能走還要能撐
             └── 物（火把、資源）──→ 沒資源就是送死，但有資源不等於能到
```

這三者是 **AND** 關係——缺一不可。

- **志** = 改革的意願與方向（王安石不缺這個）
- **力** = 執行力、堅持力、面對打壓不退縮的韌性（他懷疑同僚缺這個）
- **物** = 皇帝的信任、執政的職權、朝廷的資源（當時他還沒有，但很快就會有了）

### 隱喻的具體對照

| 遊山元素 | 變法對應 |
|----------|----------|
| 褒禪山深穴 | 北宋積弊之深、改革之險 |
| 火把 | 皇帝的授權、改革的資源（預算、人才） |
| 「火且盡」的判斷 | 資源有限論——保守派喊的「國庫空虛、不可妄動」 |
| 半途退出 | 改革半途而廢——范仲淹的教訓 |
| 「悔其隨之」 | 王安石對自己的自我要求：下次絕不妥協 |
| 「盡吾志也而不能至者，可以無悔矣」 | **變法的核心綱領——不是成功與否的問題，而是有沒有走到最後一刻的問題** |

---

## 五、一句話總結

> **〈遊褒禪山記〉不是一篇遊記，而是一篇改革宣言——王安石用一次失敗的探洞，建構了變法的條件哲學：志（方向）、力（執行）、物（資源），三者並舉，缺一不可，而最致命的是「半途喊停的人」——他的變法預言在十五年後全面應驗，也因為同樣的原因崩於中途。**

---

## 六、附論：此文的歷史回響

王安石後來於熙寧二年（1069）拜參知政事、三年（1070）拜相（同中書門下平章事），推行熙寧變法，正如他早在褒禪山中預言的那樣：反對者不是沒有資源，也不是否定變法的方向，而是「在關鍵時刻退了」。

司馬光、呂惠卿、韓琦——這些人在不同階段都當過那個「半途喊停的欲出者」。有的退得太早（司馬光），有的走到一半反過來搶火把（呂惠卿）。王安石晚年退居金陵，回憶一生，不知是否想起褒禪山那個幽暗的洞穴，和那個說「火且盡」的聲音。

**成也火把，敗也火把。**
**遊山如此，變法亦然。**
