## 1. 文章結構與起承轉合

### 1.1 全文結構總覽

〈信陵君救趙論〉是明代唐宋派古文大家唐順之的翻案史論代表作，收於《荊川先生文集》。全文約九百五十字，篇幅精悍，卻完成了從「破題」到「定讞」的完整論證閉環。唐順之以「心術」為核心武器——不去爭論竊符行為本身的是非，而是從信陵君的內心動機入手，將一個千古美談徹底翻轉為一場「以私義害公義」的政治事故。

全文五個自然段，構成一個精密推進的邏輯鏈條：

| 段落 | 核心內容 | 功能 |
|:----:|----------|:----:|
| **第1段** | 承認世人對竊符的批評 → 但否定竊符是真正的罪 → 從戰略高度肯定救趙（救趙即救魏、救六國）→ 反問「夫奚不可者？」 | 破題——先退一步，再進三步 |
| **第2段** | 轉折——「然則信陵果無罪乎？」→ 真正該批評的是信陵君的心 → 趙國、平原君、信陵君皆「不知有王」→ 假設推理（他國不救、非姻戚不救）→ 「趙王與社稷之輕重，不能當一平原公子」 | 提出翻案核心論點 |
| **第3段** | 批評侯生、如姬亦「知有信陵，不知有王」→ 給出三種死諫替代方案 → 「何爲計不出此？」→ 幸姬、鄰國、夷門野人皆知有公子 → 「魏僅有一孤王耳」 | 深化論證，提出替代方案 |
| **第4段** | 從世風著眼——「背公死黨」之習、「君若贅旒」之久 → 信陵之罪不專在竊符：為魏、為六國竊符猶可；為趙、為親戚縱求符亦罪 | 深一層，由個人罪推及時代病 |
| **第5段** | 再翻一層——魏王亦不得無罪（兵符藏於臥內，木朽蛀生、履霜之漸）→ 人臣植黨之戒、人君失權之戒 → 以《春秋》書法作結 | 定讞——罪責從個人擴及君臣雙方 |

### 1.2 起承轉合分析

| 結構 | 對應段落 | 核心內容 | 論證策略 |
|:----:|:--------:|----------|:---------|
| **起** | 第1段 | 先承認世人觀點（竊符是罪）→ 再否定（此未足以罪信陵）→ 從戰略高度肯定救趙（救趙即救魏、救六國）→ 反問「夫奚不可者？」 | **以退為進，先立後破**。唐順之開篇不做攻擊，反而先替信陵君辯護——「竊符有什麼不可以的？」讀者正以為他要為信陵君翻案，卻不知這只是設下的一個陷阱 |
| **承** | 第2段 | 「然則信陵果無罪乎？曰：又不然也。」→ 鎖定真正目標：「余所誅者，信陵君之心也」→ 指責趙國「知有信陵，不知有王」→ 指責信陵君「知有婚姻，不知有王」→ 假設推理收網 | **翻轉方向，鎖定目標**。從竊符的「事」轉向心術的「心」——這是最關鍵的一步。一旦讀者接受了「心術」這個戰場，信陵君就無法防禦了 |
| **轉** | 第3-4段 | 第3段：批評侯生、如姬亦「知有信陵而不知有王」→ 提出三種死諫方案（激諫於王、死於王前）→ 「何爲計不出此？」→ 收於「魏僅有一孤王耳」；第4段：推開一筆論世風（「君若贅旒久矣」）→ 信陵之罪「固不專係乎符之竊不竊也」 | **最凌厲的一轉**。用假設推理將信陵君的「義」從天下大義降格為婚姻私義，再用三種替代方案反襯其選擇之誤，最後把個人之罪放進「背公死黨」的時代病中 |
| **合** | 第5段 | 再翻一層——「魏王亦不得爲無罪也」：兵符藏於臥內而能竊，木朽蛀生、履霜之漸 → 「信陵君可以爲人臣植黨之戒，魏王可以爲人君失權之戒」→ 以「《春秋》書葬原仲、翬帥師」收束 | **一句定讞，首尾呼應**。與開頭「此未足以罪信陵也」相呼應——開頭只否定竊符之罪，末段「信陵之罪，固不專係乎符之竊不竊也」則把罪名安在「心」上；並補一刀：魏王失權亦有罪，罪責由個人擴及君臣雙方 |

### 1.3 起承轉合結構圖解

```
起（第1段）：先退一步——「竊符不足罪信陵」
    │
    ├─ 肯定救趙的戰略正確性（救趙即救魏、救六國）
    ├─ 反問——「夫奚不可者？」（引君入甕）
    │
    ▼
承（第2段）：突然翻轉——「余所誅者，信陵君之心也」
    │
    ├─ 將戰場從「行為」轉向「心術」
    ├─ 趙國：知有信陵，不知有王
    └─ 信陵君：知有婚姻，不知有王
    │      └─ 假設推理：「使禍不在趙……」「使趙無平原……」
    ▼
轉（第3-4段）：最強翻案 + 替代方案 + 時代病
    │
    ├─ 第3段：侯生、如姬同罪 → 三種死諫方案 →「魏僅有一孤王耳」
    └─ 第4段：世風「背公死黨」「君若贅旒」→ 竊符猶可，為親戚求符亦罪
    │
    ▼
合（第5段）：再翻一層——魏王亦不得無罪
    ├─ 木朽蛀生、履霜之漸 → 植黨之戒、失權之戒
    └─ 以《春秋》書法作結：「嗟夫！聖人之爲慮深矣！」
```

### 1.4 結構特點

1. **以退為進的破題術**：開篇不攻擊，反而先替信陵君辯護——「竊魏之符以紓魏之患……夫奚不可者？」這是中國論說文中最經典的開局策略：先承認對手的合理性，再從更高層次推翻這個合理性。讀者跟著唐順之走進第一層（竊符合理），卻不知道後面還有三層在等著。

2. **「心術」作為翻案槓桿**：全文的結構核心是一個「心」字。唐順之巧妙地繞開了「竊符」這個事實（因為救趙的戰略合理性確實無法否認），轉而從「為什麼竊符」這個動機問題切入。一旦把戰場從「事」轉向「心」，信陵君就失去了辯解的餘地——因為動機永遠比行為更難自證清白。

3. **假設推理的連環衝擊**：第2段的兩個「使……則……」假設構成了全文最強的打擊點。這種假設推理之所以有力，是因為它不需要推翻任何歷史事實——它只是在問一個問題：「如果情境換了，信陵君還會這樣做嗎？」而答案（不會）直接證明了信陵君的「義」是有條件的、是私人的。

4. **層層翻剝、波瀾迭起的閉環結構**：開頭「此未足以罪信陵也」只是否定一個罪名；第4段「信陵之罪，固不專係乎符之竊不竊也」把罪名從「竊符之事」轉到「無君之心」；第5段更進一步，連魏王一併論罪——「不特眾人不知有王，王亦自爲贅旒也」。全文如同一場審判，先駁回一項指控，再提出更重的指控，最後連審判者與被審判者的關係都重新定義，無懈可擊。

## 2. 修辭與論證手法

### 2.1 修辭手法分析

| 修辭手法 | 原文例證 | 作用與效果 |
|:---------|----------|:-----------|
| **設問** | 「然則信陵果無罪乎？曰：又不然也。」 | 全文最重要的結構轉折點。自問自答，用「又不然」將讀者從第一層（竊符合理）引導到第二層（心術有罪） |
| **反問** | 「夫奚不可者？」／「何爲計不出此？」 | 開篇與第3段末的反問，無需回答而答案自明：前者誘讀者先接受救趙之合理，後者逼問三種死諫方案何以不用——一個「引君入甕」，一個「搖首興嘆」 |
| **對偶** | 「救趙者，亦以救魏；救一國者，亦以救六國也。」 | 兩句並列的寬對，節奏明快，強化救趙的戰略合理性——正是為後文翻案鋪墊的「誘餌」 |
| **層遞** | 「其竊符也，非爲魏也，非爲六國也，爲趙焉耳；非爲趙也，爲一平原君耳。」 | 否定範圍層層收縮：魏→六國→趙→一平原君，動機愈剝愈顯，最終鎖定「為一人」，是全文最有殺傷力的句式 |
| **比喻** | 「木朽而蛀生之矣。」 | 以朽木生蛀喻君權失守、禍患自內而生——魏王寵幸如姬、疏於防範，正是竊符得以發生的根源 |
| **用典** | 「履霜之漸，豈一朝一夕也哉！」「《春秋》書葬原仲、翬帥師。」 | 前句化用《易·坤》「履霜堅冰至」，後句取《春秋》書法（葬原仲戒人臣植黨、翬帥師戒人君失權），以聖人經義為全篇定讞，收束凜然 |

（假設推理、對比、諷刺等為論證策略，見 2.2、2.3；本文議論性強，少用鋪陳性修辭，故修辭表僅列此六條。）

### 2.2 論證策略——「三步剝皮法」

〈信陵君救趙論〉最精彩的論證策略是唐順之的「三步剝皮法」——像剝洋蔥一樣，每剝一層，信陵君的形象就更加不堪：

**第一步：先替對手說話（第1段）**

> 「論者以竊符爲信陵君之罪，余以爲此未足以罪信陵也。」

唐順之開篇先承認世人對信陵君的指控（竊符），然後否定這個指控。他從戰略角度論證救趙的合理性——「趙，魏之障也。趙亡，則魏且爲之後」——進而得出結論：救趙就是救魏，救一國就是救六國。

這種策略的高明之處在於：唐順之建立了一個「客觀公正」的形象。讀者會想：「這個作者不是來罵信陵君的，他反而在為信陵君辯護。」這種印象讓讀者在後面的「翻案」中失去了防備。

**第二步：提出自己的指控（第2段）**

> 「然則信陵果無罪乎？曰：又不然也。余所誅者，信陵君之心也。」

用一個設問完成方向的轉折——「信陵君真的沒有罪嗎？不，還是有罪的。」但罪不在竊符，而在「心」。唐順之將戰場從「事」（竊符）轉向了「心」（動機），這是一個無法反駁的轉移——因為沒有人能證明信陵君的內心。

然後他從三個角度論證信陵君「心中無王」：趙國求救於信陵而非魏王 → 平原君以婚姻關係刺激信陵 → 信陵君自認因婚姻而救 → 最終結論：「是信陵知有婚姻，不知有王也」。再用兩個假設推理（「使禍不在趙」「使趙無平原」）收網，得出「趙王與社稷之輕重，不能當一平原公子」。

**第三步：推導出更嚴重的結論（第3-5段）**

第三步分為三個層次：

第一層（第3段）：批評的範圍由信陵君擴大到整個「救趙團隊」——「侯生教公子以竊符，如姬爲公子竊符於王之臥內，是二人亦知有信陵，不知有王也」。並為信陵君、侯生、如姬各設計一種死諫方案（「曷若以脣齒之勢激諫於王，不聽，則以其欲死秦師者而死於魏王之前，王必悟矣」），反襯出他們實際選擇的荒唐。收於「內則幸姬，外則鄰國，賤則夷門野人，又皆知有公子，不知有王。則是魏僅有一孤王耳」。

第二層（第4段）：把個人之罪放進時代背景——「自世之衰，人皆習於背公死黨之行而忘守節奉公之道」「蓋君若贅旒久矣」，故「信陵之罪，固不專係乎符之竊不竊也」：「其爲魏也，爲六國也，縱竊符猶可；其爲趙也，爲一親戚也，縱求符於王，而公然得之，亦罪也」。

第三層（第5段）：反手再論魏王之罪——「兵符藏於臥內，信陵亦安得竊之？」「木朽而蛀生之矣」「履霜之漸，豈一朝一夕也哉」。最終判決：「故信陵君可以爲人臣植黨之戒，魏王可以爲人君失權之戒」，以「《春秋》書葬原仲、翬帥師。嗟夫！聖人之爲慮深矣！」作結。

### 2.3 節奏控制

〈信陵君救趙論〉的節奏控制極具辯論色彩：

- **開篇從容（第1段）**：不急著批評，先從容論證救趙的戰略意義——「趙，魏之障也。趙亡，則魏且爲之後。趙、魏，又楚、燕、齊諸國之障也……」這段節奏舒緩，像在和朋友聊天，讓讀者放下戒心
- **轉折急促（第2段開頭）**：「然則信陵果無罪乎？曰：又不然也。」——用短促的設問和否定，突然切換節奏，從從容變為凌厲
- **核心攻擊密集（第2-3段）**：假設推理、層層遞進、三番死諫方案——節奏越來越快，論證越來越密，讀者來不及喘息
- **議論愈轉愈深（第4-5段）**：由個人之罪轉入時代之病，再反手論魏王之罪，末段連用四問（「則信陵安得樹私交於趙？趙安得私請救於信陵？如姬安得銜信陵之恩？信陵安得賣恩於如姬？」）如連珠炮，最後以《春秋》書法與「嗟夫！」收束——古文觀止評曰：「一層深一層，一節深一節，愈駁愈醒，愈轉愈刻」

### 2.4 與司馬遷的對話

〈信陵君救趙論〉最深刻的地方在於：**唐順之是在和司馬遷辯論。**

司馬遷在〈史記·魏公子列傳〉中將信陵君塑造成一個完美的英雄——禮賢下士、高義薄雲、救趙存魏。司馬遷說信陵君「名冠諸侯，不虛耳」。唐順之要做的就是推翻司馬遷的結論，但他不是捏造事實，而是用司馬遷自己提供的史料得出完全相反的結論：

- 司馬遷說信陵君「高義」→ 唐順之說：他的高義是為姻親，不是為國家
- 司馬遷說信陵君「救趙」→ 唐順之說：他救的是平原君，不是趙國
- 司馬遷說信陵君「賢」→ 唐順之說：他「賢」到心中無君

這是翻案文章的最高境界——不否定史料，只重新解釋動機。唐順之的做法堪稱「以子之矛攻子之盾」的典範。

## 3. 名句深度解析

### 3.1 「論者以竊符爲信陵君之罪，余以爲此未足以罪信陵也。」

**白話：** 評論者把竊取兵符當作信陵君的罪過，我認為這還不足以給信陵君定罪。

**賞析：**

這是全文的開篇句，也是唐順之「三步剝皮法」的第一步。其修辭藝術極其精妙：

- **「論者以……余以爲……」的對立結構**：將「世人」與「我」並列，建立一個「眾人皆醉我獨醒」的話語姿態。唐順之不是要與世人爭論，而是要告訴世人：你們看問題的角度錯了。

- **「此未足以罪信陵也」的否定策略**：不是直接說「竊符無罪」，而是說「還不足以定罪」。這個「不足以」為後面的翻案留下了空間——「不足以」不代表「沒有罪」，只是「罪名不對」。「不足以」暗示還有更大的罪在後面。

- **語氣的微妙控制**：這句話的語氣不是攻擊性的，而是裁判式的。唐順之不像一個辯論者，而像一個高明的法官——先駁回一個指控（竊符），再提出新的指控（心術）。這種語氣讓讀者覺得他很客觀、很公正。

### 3.2 「余所誅者，信陵君之心也。」

**白話：** 我所譴責的，是信陵君的存心（內心動機）。

**賞析：**

這是全文的「文眼」——全文所有的論證，歸根結底就是這一句話。它出現在第2段開頭（「然則信陵果無罪乎？曰：又不然也」之後），一出現便為全篇定了調；第4段「信陵之罪，固不專係乎符之竊不竊也」、第5段「人臣植黨之戒」都是這句「誅心」之論的展開。

- **「誅」字的凌厲**：「誅」本義是「殺戮」，引申為「譴責、批判」。用「誅」而不是「論」「評」「議」，顯示了唐順之的態度——不是溫和的討論，而是嚴厲的審判。但「誅」的對象是「心」而不是「人」，這又保留了倫理的空間：我殺的不是你這個人，而是你心中的那個念頭。

- **「心」字的關鍵定位**：唐順之選擇「心」作為全文的核心概念，有深刻的理學背景。宋明理學的核心命題之一就是「心術」——一個人的行為是否正確，關鍵不在於行為本身，而在於行為背後的動機。陽明心學講「致良知」，唐順之這裡用的是同一套話語體系：批評信陵君不是因為他做了什麼（救趙），而是因為他的「心」不純（為婚姻而不是為國家）。

- **全文的邏輯樞紐**：這句話出現在第2段開頭，正是全文從「起」到「承」的轉折點。前一段在談「事」（竊符、救趙），從這一句開始轉向「心」（動機、心術）。一旦「心」成為戰場，信陵君就再也無法為自己辯護了——沒人能證明自己的動機是純粹的。

### 3.3 「使禍不在趙，而在他國，則雖撤魏之障，撤六國之障，信陵亦必不救。使趙無平原，或平原而非信陵之姻戚，雖趙亡，信陵亦必不救。」

**白話：** 假如禍患不在趙國，而在其他國家，那麼即使撤去魏國的屏障、撤去六國的屏障，信陵君也一定不會去救。假如趙國沒有平原君，或者平原君不是信陵君的姻親，那麼即使趙國滅亡，信陵君也一定不會去救。

**賞析：**

這是全文最核心的論證段落，也是唐順之翻案的最強一擊。其論證力量來自兩個方面：

- **雙重假設的疊加效應**：第一個假設（不是趙國）排除「為天下大勢」的可能；第二個假設（不是平原君）排除「為趙國」的可能。兩個假設疊加後，唯一的解釋就是「為平原君個人」。這種疊加假設的論證手法在邏輯學上叫做「排除法」——當所有其他可能性都被排除後，剩下的就是真相。

- **「必不救」的絕對語氣**：「必不救」三個字斬釘截鐵——不是「可能不救」，而是「一定不救」。這種絕對化的表述顯示了唐順之對自己判斷的極度自信。讀者會想：他為什麼這麼肯定？因為事實已經很清楚——信陵君和趙國沒有其他關係，唯一的連結就是平原君這個姻親。

- **修辭上的層層遞進**：第一個假設從「在他國」開始，推到「撤魏之障」（魏國的屏障），再推到「撤六國之障」（六國的屏障）——範圍不斷擴大，情況越來越嚴重，但結論始終不變：「信陵亦必不救」。這種「越嚴重越不救」的對比，將信陵君的「自私」暴露無遺。

### 3.4 「則是趙王與社稷之輕重，不能當一平原公子，而魏之兵甲所恃以固其社禝者，祇以供信陵君一姻戚之用。」

**白話：** 這樣看來，趙國的國君和江山社稷的份量，還抵不上平原君一個人；而魏國的軍隊——原本是用來保衛國家的——只不過是給信陵君用來送給一個姻親的人情。

**賞析：**

這是全文最具殺傷力的一句話，可以說是唐順之對信陵君的「判詞」。其修辭藝術達到了巔峰：

- **「趙王與社稷」vs.「一平原公子」的強烈對比**：一國之君 + 整個江山社稷（最大的份量）vs. 一個人（最小的份量）——「不能當」三個字將這種不對等關係徹底暴露。讀者讀到這裡，會不由自主地倒吸一口冷氣：真的有這麼嚴重嗎？但回過頭看前面的論證，又不得不承認唐順之說得有理。

- **「祇以供……之用」的諷刺語氣**：「祇以」二字帶有強烈的輕蔑——這麼大的國家軍隊，這麼重要的軍事力量，竟然只是信陵君用來送人情的一件禮物。「供……之用」的句式將國家軍隊降格為日常用品，嘲諷意味十足。

- **「姻戚」二字的精準打擊**：唐順之不用「友人」「知己」「義氣」等詞，而用「姻戚」（婚姻親戚）。「姻戚」是一個中性的、甚至是帶有功利色彩的詞——它不是基於道義的結合，而是基於婚姻的血緣關係。用這個詞來描述信陵君與平原君的關係，從根本上消解了「義」的崇高性。

### 3.5 「其爲趙也，爲一親戚也，縱求符於王，而公然得之，亦罪也。」

**白話：** 如果是為了趙國、為了一個親戚，那麼縱然向魏王求取兵符、公然得到它，也同樣是罪過。

**賞析：**

這是第4段的「深文」之筆，也是唐順之把論點推到極致的關鍵句：

- **「縱竊符猶可」與「縱求符亦罪」的對照**：前文「其爲魏也，爲六國也，縱竊符猶可」——為公義，竊符都可原諒；此句「其爲趙也，爲一親戚也，縱求符於王，而公然得之，亦罪也」——為私義，連公然求符都有罪。一正一反，把定罪標準從「手段是否合法」徹底轉到「動機是否為公」，是全文「誅心」邏輯最鋒利的一刀。

- **與「余所誅者，信陵君之心也」的呼應**：開頭說罪不在竊符而在「心」，此句正是「心術定罪」的具體化——同樣拿兵符，動機為公則無罪、動機為私則有罪。唐順之把「竊符」與「存趙」之辨收束為「公義」與「私義」之辨。

- **句式上的層層加碼**：「縱……猶可」「縱……亦罪」兩句對舉，語氣由寬鬆驟轉嚴厲，讀者還未及為信陵君鬆一口氣，就已被推入「亦罪也」的定讞。

### 3.6 「夫竊符之計，蓋出於侯生，而如姬成之也。」

**白話：** 那竊取兵符的計謀，是出自侯生（侯嬴），而由如姬完成的。

**賞析：**

這句話雖然不如其他名句那麼震撼，但在論證結構中有其特殊作用：

- **擴大批評範圍**：唐順之不是只批評信陵君一個人，而是將侯生、如姬也納入批評對象。這不僅讓批評更全面，而且暗示了一個更深層次的問題：不只是信陵君「心中無王」，他周圍的人（門客、寵妃）也都「心中無王」。這說明「心中無王」不是信陵君一個人的問題，而是整個魏國權力結構的問題。

- **為替代方案做鋪墊**：緊接著這句話，唐順之提出了對信陵君、侯生、如姬三人的三種死諫方案——他們本可以用諫諍、死諫的方式來救趙，但他們選擇了最極端的方式。這種「先陳述事實，再提出更好方案」的論證結構，讓批評更加有力：不是說救趙不對，而是說你們救趙的方式可以更好。

- **「蓋……而……成之」的敘述語氣**：這句話的語氣像是一個冷靜的歷史敘述者——不急不緩，不怒不罵。但正是這種冷靜，讓後面的批評顯得更加客觀有力。

## 4. 白話改編

以下為〈信陵君救趙論〉全文分段的現代白話翻譯，原文以 ancient-china-books 通行本（part217）為底本，便於對照理解。

### 原文：第一段（破題——先退一步）

> 論者以竊符爲信陵君之罪，余以爲此未足以罪信陵也。夫強秦之暴亟矣，今悉兵以臨趙，趙必亡。趙，魏之障也。趙亡，則魏且爲之後。趙、魏，又楚、燕、齊諸國之障也，趙、魏亡，則楚、燕、齊諸國爲之後。天下之勢，未有岌岌於此者也。故救趙者，亦以救魏；救一國者，亦以救六國也。竊魏之符以紓魏之患，借一國之師以分六國之災，夫奚不可者？

**白話：** 評論者把竊取兵符當作信陵君的罪過，我認為這還不足以給信陵君定罪。秦國的暴虐已經到了極點，如今傾全國兵力進逼趙國，趙國必將滅亡。趙國是魏國的屏障；趙國滅亡，魏國就會跟著步其後塵。趙國、魏國，又是楚國、燕國、齊國諸國的屏障；趙、魏滅亡，楚、燕、齊諸國也會步其後塵。天下的形勢，沒有比這更危急的了。所以救趙國，也就是救魏國；救一個國家，也就是救六國。竊取魏國的兵符來解除魏國的禍患，借助一國之師來分擔六國的災難——這有什麼不可以的呢？

### 原文：第二段（翻案——鎖定心術）

> 然則信陵果無罪乎？曰：又不然也。余所誅者，信陵君之心也。信陵一公子耳，魏固有王也。趙不請救於王，而諄諄焉請救於信陵，是趙知有信陵，不知有王也。平原君以婚姻激信陵，而信陵亦自以婚姻之故，欲急救趙，是信陵知有婚姻，不知有王也。其竊符也，非爲魏也，非爲六國也，爲趙焉耳。非爲趙也，爲一平原君耳。使禍不在趙，而在他國，則雖撤魏之障，撤六國之障，信陵亦必不救。使趙無平原，或平原而非信陵之姻戚，雖趙亡，信陵亦必不救。則是趙王與社稷之輕重，不能當一平原公子，而魏之兵甲所恃以固其社禝者，祇以供信陵君一姻戚之用。幸而戰勝，可也，不幸戰不勝，爲虜於秦，是傾魏國數百年社稷以殉姻戚，吾不知信陵何以謝魏王也。

**白話：** 那麼信陵君果真沒有罪嗎？回答是：又不是這樣。我所譴責的，是信陵君的存心（內心動機）。信陵君不過是一個公子罷了，魏國本來有國君在。趙國不向魏王求救，卻一次次懇切地向信陵君求救，這是趙國只知道有信陵君，不知道有魏王。平原君用婚姻關係激發信陵君，而信陵君也自以為是為了婚姻的緣故急著救趙，這是信陵君只知道有婚姻，不知道有魏王。他竊取兵符，不是為了魏國，不是為了六國，只是為了趙國罷了；不是為了趙國，只是為了一個平原君罷了。假使禍患不在趙國而在別的國家，那麼即使撤去魏國的屏障、撤去六國的屏障，信陵君也一定不會去救。假使趙國沒有平原君，或者平原君不是信陵君的姻親，那麼即使趙國滅亡，信陵君也一定不會去救。這樣看來，趙王和國家社稷的份量，還抵不上一個平原君；而魏國的兵甲——原本賴以鞏固社稷的——只是供信陵君一個姻親使用罷了。僥倖打勝了，還可以；不幸打敗了，被秦國俘虜，這就是拿魏國數百年的社稷去為一個姻親殉葬，我不知道信陵君拿什麼去謝魏王。

### 原文：第三段（擴大批評——替代方案）

> 夫竊符之計，蓋出於侯生，而如姬成之也。侯生教公子以竊符，如姬爲公子竊符於王之臥內，是二人亦知有信陵，不知有王也。余以爲信陵之自爲計，曷若以脣齒之勢激諫於王，不聽，則以其欲死秦師者而死於魏王之前，王必悟矣。侯生爲信陵計，曷若見魏王而說之救趙，不聽，則以其欲死信陵君者而死於魏王之前，王亦必悟矣。如姬有意於報信陵，曷若乘王之隙而日夜勸之救，不聽，則以其欲爲公子死者而死於魏王之前，王亦必悟矣。如此，則信陵君不負魏，亦不負趙；二人不負王，亦不負信陵君。何爲計不出此？信陵知有婚姻之趙，不知有王。內則幸姬，外則鄰國，賤則夷門野人，又皆知有公子，不知有王。則是魏僅有一孤王耳。

**白話：** 那竊取兵符的計謀，是出自侯生（侯嬴），而由如姬完成的。侯生教公子竊取兵符，如姬為公子在魏王的臥室裡竊取兵符——這兩個人也是只知道有信陵君，不知道有魏王。我認為，信陵君為自己打算，何不用「唇亡齒寒」的形勢去激切諫阻魏王；王不聽，就把那本要與秦軍死戰的決心，用在死在魏王面前，王一定會醒悟。侯生為信陵君打算，何不去見魏王勸說他救趙；王不聽，就用那本要為信陵君赴死的決心死在魏王面前，王也一定會醒悟。如姬有心報答信陵君，何不趁魏王閒暇時日夜勸他救趙；王不聽，就用那本要為公子赴死的決心死在魏王面前，王也一定會醒悟。這樣一來，信陵君既沒有辜負魏國，也沒有辜負趙國；侯生、如姬二人既沒有辜負魏王，也沒有辜負信陵君。為什麼計策不從這裡出呢？信陵君只知道有婚姻之親的趙國，不知道有魏王。內有寵姬，外有鄰國，賤有夷門守門人，又都只知道有公子，不知道有魏王。那麼魏國只剩下一個孤零零的王了。

### 原文：第四段（深一層——時代之病）

> 嗚呼！自世之衰，人皆習於背公死黨之行而忘守節奉公之道，有重相而無威君，有私仇而無義憤，如秦人知有穰侯，不知有秦王，虞卿知有布衣之交，不知有趙王，蓋君若贅旒久矣。由此言之，信陵之罪，固不專係乎符之竊不竊也。其爲魏也，爲六國也，縱竊符猶可。其爲趙也，爲一親戚也，縱求符於王，而公然得之，亦罪也。

**白話：** 唉！自從世道衰敗，人們都習慣了背棄公義、為朋黨賣命的行徑，而忘了守節奉公的道理；有權重的宰相而沒有有威嚴的君主，有私人的仇怨而沒有公義的憤慨。像秦國人只知道有穰侯，不知道有秦王；虞卿只知道有布衣之交，不知道有趙王——君主像多餘的裝飾品已經很久了。由此說來，信陵君的罪過，本來不專門繫於兵符竊不竊。他如果是為了魏國、為了六國，縱然竊取兵符還可以；如果是為了趙國、為了一個親戚，縱然向魏王求取兵符而公然得到它，也同樣是罪過。

### 原文：第五段（再翻一層——魏王亦有罪，定讞）

> 雖然，魏王亦不得爲無罪也。兵符藏於臥內，信陵亦安得竊之？信陵不忌魏王，而徑請之如姬，其素窺魏王之疏也；如姬不忌魏王，而敢於竊符，其素恃魏王之寵也。木朽而蛀生之矣。古者人君持權於上，而內外莫敢不肅。則信陵安得樹私交於趙？趙安得私請救於信陵？如姬安得銜信陵之恩？信陵安得賣恩於如姬？履霜之漸，豈一朝一夕也哉！由此言之，不特眾人不知有王，王亦自爲贅旒也。故信陵君可以爲人臣植黨之戒，魏王可以爲人君失權之戒。《春秋》書葬原仲、翬帥師。嗟夫！聖人之爲慮深矣！

**白話：** 雖然如此，魏王也不能說沒有罪。兵符藏在臥室之內，信陵君又怎麼能竊取呢？信陵君不顧忌魏王，而徑直去請求如姬，這是他平時看穿了魏王的疏忽；如姬不顧忌魏王而敢於竊取兵符，這是她平時倚仗魏王的寵愛。木頭朽爛了，蛀蟲就生出來了。古代君主在上掌握權柄，內外沒有誰敢不肅然恭敬。那麼信陵君怎麼能在趙國結下私交？趙國怎麼能私下向信陵君求救？如姬怎麼能感念信陵君的恩德？信陵君怎麼能向如姬施恩？踩到霜便漸進於堅冰，豈是一朝一夕的事呢！由此說來，不只是眾人不知道有魏王，魏王自己也把自己變成了多餘的裝飾品。所以信陵君可以作為人臣培植私黨的警戒，魏王可以作為人君大權旁落的警戒。《春秋》記載「葬原仲」、「翬帥師」。唉！聖人的用心是多麼深遠啊！

    ├─ 侯生「知有信陵，不知有王」
    ├─ 如姬「知有信陵，不知有王」
    └─ 「內則幸姬，外則鄰國，賤則夷門野人，又皆知有公子」——魏僅有一孤王
    │

    ├─ 方案一（對信陵君）：以脣齒之勢激諫於王 → 王必悟
    ├─ 方案二（對侯生）：見魏王而說之救趙 → 王亦必悟
    ├─ 方案三（對如姬）：乘王之隙而日夜勸之救 → 王亦必悟

    │
    ▼

### 5.3 層層翻剝的論證技巧

唐順之此文最精彩之處在於**層層翻剝**——像剝洋蔥一樣，每翻一層，信陵君行為的真相就更加赤裸：

1. **第一層（現象）**：信陵君竊符救趙 → 世人指責他竊符 → 唐順之說：竊符不是問題，救趙是對的

2. **第二層（標準）**：問題不在「做什麼」（竊符），而在「為什麼做」（動機）→ 「余所誅者，信陵君之心也」

3. **第三層（事實）**：趙國向信陵求救而非向魏王 → 平原君以婚姻激信陵 → 信陵君自認以婚姻故救趙 → 所有人「知有信陵而不知有王」

4. **第四層（假設推理）**：如果不是趙國 → 不救；如果不是平原君 → 不救 → 結論：所謂高義，不過是婚姻私義

5. **第五層（替代方案）**：信陵君、侯生、如姬各有更好的選擇（諫諍、死諫）→ 但他們一個都沒選 → 說明他們從根本上就「心中無王」

6. **第六層（定讞）**：由「竊符不足罪」到「爲一親戚也，縱求符於王而公然得之，亦罪也」——個人之罪再推入時代之病（「君若贅旒久矣」），最後連魏王一同論罪（「人君失權之戒」），全案定讞

### 5.4 唐順之翻案史論的方法論

〈信陵君救趙論〉集中體現了唐順之史論的方法論精華：

| 方法論特徵 | 在〈信陵君救趙論〉中的體現 |
|:-----------|:---------------------------|
| **翻案思維** | 將信陵君從「千古義士」翻轉為「以私義害公義的權臣」——不否認救趙的戰略效果，只追問動機 |
| **心術論** | 將戰場從「行為」轉向「動機」——「余所誅者，信陵君之心也」。這是宋明理學「心即理」在史論中的應用 |
| **假設推理** | 用兩個「使……則……」的假設論證鎖定信陵君的真實動機——這比指著歷史事實罵人高明得多 |
| **替代方案論證** | 提出三種死諫方案（諫諍、死諫）反襯信陵君選擇的錯誤——不是說不能救趙，而是說可以更正確地救趙 |
| **君臣倫理優先** | 以儒家君臣大義為最高判斷標準——為公義「縱竊符猶可」，為私義「縱求符亦罪」 |
| **波瀾迭起** | 由信陵君一人之罪，推到侯生、如姬，再推到時代世風（「君若贅旒」），最後反手論魏王之罪——一層深一層，一節深一節 |
