# 〈鴻門宴〉背景資料

> **軍師案語**：讀〈鴻門宴〉，不可只當作英雄傳奇讀，須以兵棋推演之心態逐寸拆解。司馬遷以文字布陣，此篇乃兵法、人心、時勢三者交織之極品。

---

## 一、座標定位

| 項目 | 內容 |
|------|------|
| **出處** | 《史記》卷七〈項羽本紀〉，自「沛公軍霸上」至「立誅殺曹無傷。」（節選） |
| **篇名** | 〈鴻門宴〉為**後人所加的通稱篇名**，非司馬遷自訂篇題 |
| **選目** | **不在《古文觀止》222 篇選目之內**。《古文觀止》所收《史記》篇目為〈五帝本紀贊〉、〈項羽本紀贊〉（卷五·漢文）、〈秦楚之際月表〉、〈高祖功臣侯年表〉、〈伯夷列傳〉等，並無〈鴻門宴〉。本站列為「補充篇」，與 222 篇正選區隔 |
| **體裁** | 史傳散文（紀傳體本紀中的敘事段落） |
| **時代** | 秦亡之後、楚漢相爭之前 |
| **時間** | 漢元年（傳統換算作西元前206年）十二月。秦曆以十月為歲首，故「漢元年」跨西曆年界，換算為西曆的確切月份學界不一，以原書紀年「漢元年十二月」為準 |
| **地點** | 鴻門（今陝西省西安市臨潼區東、新豐一帶，驪山北麓；項羽駐軍處） |
| **事件** | 項羽設宴款待劉邦，實為一次未遂的政治斬首行動 |
| **核心命題** | 決定歷史走向的不是兵力，而是性格與判斷——項羽在宴席上的猶豫，改寫了此後四百年的天下 |

**空間格局示意**：

```
        　咸陽（秦都，已破）
              │
         灞上 ←──→ 鴻門
       (劉邦軍)     (項羽軍)
       10萬眾        40萬眾
         │             │
   函谷關封鎖    新安坑卒處
```

鴻門距劉邦駐地灞上約四十里。此四十里，是劉邦一生走過最長的路——赴宴是冒險，不去是死路，進退之間，賭的是項羽的猶豫。

## 二、時代壓力——秦亡後的權力真空

### 2.1 關鍵背景階梯

```
楚懷王約定：先入定關中者王之
         │
   劉邦先入咸陽（西元前206年十月）
         │
   劉邦封鎖函谷關，欲據關中稱王
         │
   項羽破函谷關，怒而進軍鴻門
         │
   劉邦左司馬曹無傷密告項羽
         │
   項羽下令：「旦日饗士卒，為擊破沛公軍！」
         │
   ────→ 鴻門宴
```

### 2.2 實力懸殊

| 勢力 | 兵力 | 性格標籤 | 戰略處境 |
|------|------|----------|----------|
| 項羽 | 約40萬（號稱百萬） | 暴烈／重名譽／優柔寡斷 | 軍事絕對優勢，但政治合法性不足 |
| 劉邦 | 約10萬（號稱二十萬） | 狡猾／能屈能伸／善用人 | 軍事劣勢，但搶佔先入關中的道義高地 |

**軍師研判**：四十萬對十萬，若項羽決心殺劉邦，劉邦絕無生還之機。然而項羽的猶豫救了劉邦——這是整個楚漢相爭最關鍵的轉折點。

> **數字出處**：「號稱百萬／號稱二十萬」見《史記》卷八〈高祖本紀〉與《漢書》卷一上〈高帝紀上〉，本選文（〈項羽本紀〉該段）只作「項羽兵四十萬……沛公兵十萬」，未載「號」數。

### 2.3 當時天下棋局

秦帝國在劉邦入關、秦王子嬰出降後實質滅亡（《史記》卷八〈高祖本紀〉繫此於「漢元年十月」，即鴻門宴前兩個月），但天下並未歸一：

- **關中**：秦的腹地，被劉邦佔領，約法三章，收買人心
- **山東六國舊地**：各路諸侯趁機復國，各懷鬼胎
- **楚懷王（名義共主）**：在彭城，被項羽視為傀儡
- **項羽**：戰功最高，手握最強兵團，但未正式稱尊

這是一場**沒有皇帝的天下**。誰能在權力真空中第一個坐上那個位置，誰就掌握未來四百年。

## 三、關鍵人物——飯局上的七把棋子

### 3.1 項羽（主宴者，楚霸王）

- **年齡**：約26歲（《史記》記其「初起時，年二十四」，起兵為秦二世元年／前209年，推得生於前232年；鴻門宴時約26歲）
- **位置**：坐在主位，掌握生殺大權
- **盤算**：聞劉邦欲王關中而大怒，但見劉邦卑辭謝罪後心軟，陷入「殺之不義，不殺不甘」的困境
- **致命弱點**：婦人之仁 vs 匹夫之勇（韓信後來評語），重視名譽大於實際利益
- **軍師評價**：項羽殺人從不手軟——就在鴻門宴前不久，他才在新安坑殺秦降卒「二十餘萬人」（其確切年月史無明文，僅能定在章邯投降〔秦二世三年七月〕之後、項羽破函谷關〔漢元年十一月〕之前），日後又放殺義帝；唯獨在殺劉邦這件事上猶豫，因為「宴會」的社交規則束縛了他。他不是不忍殺人，而是不忍在**公開場合**殺一個**向他低頭的人**。這是性格決定的死穴。（按時序：坑降卒在前、鴻門宴居中、弒義帝在後，三者不可倒置。）

### 3.2 劉邦（赴宴者，後來的漢高祖）

- **年齡**：約50歲（生於前256年，鴻門宴時50歲上下，比項羽年長約二十四歲；然而他在席上自稱「臣」、居「北嚮坐」——面向北方而坐，於秦漢室內宴飲之序敬陪末座，年紀長而姿態低）
- **位置**：坐在客位（面北），自居臣下，賠盡不是
- **盤算**：活命是第一優先，尊嚴一文不值。他算準項羽好面子，只要自己態度放得夠低，項羽就下不了手
- **關鍵動作**：以「臣」自稱、解釋關中佈防是為項羽而設、離席如廁借機逃脫
- **軍師評價**：鴻門宴上劉邦的每一句話都是謊言，但這些謊言恰到好處地餵養了項羽的自尊心。劉邦的生存技術——**永遠知道對手想要聽什麼**——在此達到巔峰。

### 3.3 范增（項羽謀士，亞父）

- **年齡**：約72歲（《史記》記其往說項梁時「年七十」，時為秦二世二年／前208年；鴻門宴在前206年，實際約七十二歲。舊稿作「約70歲」，係逕取本傳「年七十」之數）
- **位置**：項羽帳下首席謀臣，席間數次舉玉玦示意
- **盤算**：堅信劉邦「此天子氣也」，必須當場格殺，絕不留後患
- **關鍵行動**：舉玦三次（玦音同「決」，催促項羽下決心；底本作「珪」，本站正文從通行本作「玦」，見〈主筆-文章分析〉§5 異文表）、召項莊舞劍刺殺
- **失敗原因**：他低估了項羽的自尊心，也低估了項伯的背叛。老謀深算卻指揮不動年輕主帥
- **軍師評價**：范增在鴻門宴上看到了未來——劉邦必成後患——但項羽看不到。謀士的最高困境不是算不到，而是算到了卻說不聽主人。

### 3.4 張良（劉邦謀士，子房）

- **年齡**：約40餘歲（《史記》未載其生年，後人依〈留侯世家〉推估約生於前250年前後；**生年史無明載，此為推定值，不確定**）
- **位置**：劉邦帳下謀臣，席間以「臣為韓王送沛公」的第三方姿態周旋
- **盤算**：將劉邦的劣勢轉化為道義優勢，利用項伯作為內應
- **關鍵行動**：拉攏項伯、安排樊噲入帳、判斷撤退時機、進獻白璧玉斗給項羽范增
- **軍師評價**：張良的高明在於——他從不正面對抗項羽的軍力，而是用禮儀和人情來瓦解項羽的決心。白璧玉斗不是禮物，是**階梯**：讓項羽下台階的階梯。軍師當如是。

### 3.5 樊噲（劉邦護衛，鴻門宴上的破局者）

- **身份**：劉邦連襟（娶呂后妹），以屠狗為業起家
- **位置**：帳外護衛，聞急闖帳——這是全宴最戲劇性的時刻
- **盤算**：沒有盤算，純粹是「主公有難我必護之」的忠勇
- **關鍵行動**：「擁盾撞入」帳中、「瞋目視項王頭髮上指目眥盡裂」、生啖彘肩、義正辭嚴指責項羽
- **軍師評價**：文人罵人叫說服，武將罵人叫威脅。樊噲那一番話其實跟劉邦說的一樣——都是劉邦是功臣你項羽不能殺——但從樊噲嘴裡說出來，項羽感到了**壓力**。因為這是戰將對戰將的對話，沒有文人的迂迴。樊噲的存在讓項羽意識到：劉邦的部下是願意為他拼命的。

### 3.6 項莊（舞劍者）

- **身份**：項羽部將。《史記》此段未交代他與項羽的親屬關係，舊注多稱其為項羽從弟（堂弟），**正史無明文，不確定**
- **位置**：受范增之命，以「軍中無以為樂，請以劍舞」為名行刺
- **目的**：原文作「今者項莊拔劍舞，其意常在沛公也」（張良語）；後世通稱的「項莊舞劍，意在沛公」即由此濃縮而成
- **結局**：項伯亦起舞，「常以身翼蔽沛公，莊不得擊」
- **軍師評價**：項莊是一個執行者，不是決策者。他舞劍的每一個動作都在等項羽下令，但項羽始終沉默。沒有主帥的授意，任何刺客都不敢真的刺下去——因為萬一項羽當場翻臉，死的是自己。

### 3.7 項伯（項羽季父，內應者）

- **身份**：項羽季父（《史記》原文：「楚左尹項伯者，項羽季父也」），但與張良有舊交；張良曾在他殺人時救他一命
- **位置**：叛徒——夜奔劉邦軍通風報信，席間以身護劉邦，阻擋項莊劍勢
- **動機**：私誼大於公義（救張良→被劉邦收買→結為兒女親家）
- **關鍵作用**：沒有項伯，劉邦根本不會赴宴；沒有項伯阻擋，項莊的劍可能已經刺穿劉邦
- **軍師評價**：項伯是全場最值得玩味的角色。他既是項羽的至親，也是整個楚軍體系最大的漏洞。項羽的失敗，從鴻門宴上「聽項伯的話」就已經註定——一個連自己叔父都管不住的人，如何管得了天下？

## 四、寫作意圖——司馬遷為何把飯局寫得比戰爭還精彩？

### 4.1 性格決定命運

太史公寫《史記》，最高宗旨並非記錄「發生了什麼」，而是揭示「為什麼發生」。鴻門宴之所以是他筆下最精彩的場景之一，是因為**一場飯局的勝負，決定了四百年大漢帝國的興亡**——而這個勝負，不是由兵力決定的，而是由人的性格決定的。

| 人物 | 性格 | 命運 |
|------|------|------|
| 項羽 | 剛愎自用、重名輕實、當斷不斷 | 錯失殺劉邦的唯一機會，終至烏江自刎 |
| 劉邦 | 忍辱負重、能屈能伸、善於用人 | 活過鴻門宴，終得天下 |

司馬遷用一場飯局告訴我們：**決定歷史的，往往不是刀劍，而是人心。**

### 4.2 戲劇結構的極致

鴻門宴的文本結構，完全符合一流戲劇的標準：

1. **懸念**：劉邦會不會被殺？（從赴宴前到逃回軍中，全場緊繃）
2. **衝突**：范增的「必殺」vs 項羽的「猶豫」
3. **轉折**：樊噲闖帳（武力破局）、劉邦遁走（智謀脫身）
4. **高潮**：范增擊碎玉斗，怒罵「豎子不足與謀」
5. **結局**：種下楚漢相爭的種子，四年後在垓下收割

### 4.3 戰爭與飯局的對比

司馬遷選擇用「飯桌上的暗流」而非「戰場上的廝殺」來決定天下歸屬，本身就體現了他的歷史洞察：

- **戰爭**（如鉅鹿之戰、垓下之圍）：勝負一目了然
- **飯局**（鴻門宴）：勝負藏在眉眼之間、酒杯之內、一句話的輕重之中

前者是力量的較量，後者是智謀與性格的較量。司馬遷告訴我們：**真正決定歷史走向的，往往是後者。**

### 4.4 司馬遷的個人投射

> **以下屬閱讀推論，非史料所載**——司馬遷受宮刑在《史記》成書過程之中，其寫作心境只能由〈太史公自序〉〈報任安書〉間接推知，不能逕指鴻門宴此段為其自我安慰。

寫《史記》時的司馬遷，已遭宮刑之辱。他筆下的鴻門宴，何嘗不是一個受盡委屈卻無力反抗者的自我安慰？劉邦在鴻門宴上的「忍」，司馬遷在獄中的「忍」——他們都選擇了活下來，然後用時間證明誰是對的。

## 五、一句話總結

> **一場沒有流血的飯局，決定了四百年大漢的命運——項羽在鴻門的猶豫，比他在鉅鹿的勇猛更具歷史重量；劉邦赴宴的每一步，都在為一個帝國鋪路。**

### 附錄二：選文範圍、版本與紀年說明

**選目判定（重要）**：〈鴻門宴〉**不在《古文觀止》222 篇選目之內**。《古文觀止》收的《史記》篇章是〈五帝本紀贊〉（074）、**〈項羽本紀贊〉（075）**、〈秦楚之際月表〉（076）、〈高祖功臣侯年表〉（077）、〈伯夷列傳〉（080）等，其中與項羽相關的是卷五·漢文的**〈項羽本紀贊〉**，不是〈鴻門宴〉。〈鴻門宴〉是後人為《史記·卷七·項羽本紀》中「沛公軍霸上」至「立誅殺曹無傷」這一段所加的通稱篇名，本站因此將本篇編為「補充篇」，不佔正選 222 篇的篇次。

**選文起訖**：自「沛公軍霸上」起，至「立誅殺曹無傷。」止，共四個自然段、**1,832 字（含標點）／1,442 字（不含標點）**。底本此段之前緊接「項羽遂入，至于戲西。」，本站即於該句後截斷。

**底本**：維基文庫《史記》卷七〈項羽本紀〉電子本（<https://zh.wikisource.org/wiki/史記/卷007>）。參校：教育部《重編國語辭典修訂本》引《史記·卷七》、維基文庫《史記》卷八〈高祖本紀〉、維基文庫《漢書》卷一上〈高帝紀〉。中國哲學書電子化計劃（ctext）因 Cloudflare 人機驗證與站方禁止抓取條款，本次未能採用。完整的異文表見〈主筆-文章分析〉§5「底本校勘」。

**紀年說明**：原書紀年作「漢元年十二月」（《漢書·高帝紀》亦作「十二月」）。秦曆以十月為歲首，「漢元年」跨西曆年界，故換算為西曆時有前206年說與前207年說之別（維基百科〈鴻門宴〉取前206年說）。本站以原書紀年「漢元年十二月」為準，西曆換算僅作參考，**確切西曆月日不確定**。另，秦王子嬰出降，《史記·高祖本紀》繫於「漢元年十月」，即鴻門宴前兩個月。

**人物生卒核對**：項羽生於前232年、死於前202年（《史記》記其「初起時，年二十四」，及烏江自刎前自述「起兵至今八歲矣」）；劉邦生於前256年、死於前195年；范增死於前204年（「疽發背而死」）。張良生年史無明載。以上除項羽、劉邦外，其餘年歲換算均係推定。
