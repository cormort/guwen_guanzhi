# 〈方山子傳〉背景資料

> 軍師按：這一篇掛著「傳」的名目，卻不是給陳慥寫的。蘇軾在一場人生最狼狽的遷謫途中，撞見了一個十九年前和他一起在馬上論兵的舊識——那個人已經把自己從世界上刪除了。於是他寫下一個人的隱，同時洩露了自己的不甘。

## 一、座標定位

| 項目 | 內容 |
|------|------|
| **出處** | 蘇軾《東坡全集》；《古文觀止》卷十一·宋文（通行本，篇題〈方山子傳〉） |
| **作者** | 蘇軾（1037–1101），字子瞻，號東坡居士，眉州眉山（今四川眉山）人 |
| **寫作時間** | 北宋神宗元豐三年（1080）正月之後不久，蘇軾初到黃州貶所時（相逢確在元豐三年正月，見「時間辨析」） |
| **寫作背景** | 烏臺詩案（元豐二年，1079）結案，蘇軾責授「檢校水部員外郎、黃州團練副使、本州安置、不得簽書公事」；元豐三年二月抵黃州 |
| **相逢地點** | 岐亭北二十五里（宋·黃州境內，在今湖北黃岡麻城一帶；據蘇軾〈岐亭五首〉敘，見「時間辨析」與文末來源） |
| **追敘地點** | 岐山／岐下（宋·鳳翔府，今陝西；與「岐亭」是兩地，極易混淆） |
| **體裁** | 傳記——但非史傳體，而是摻入作者自述與議論的「變體傳」 |
| **全文長度** | 371 字（不含標點，據底本逐字核計，詳見主筆檔「5. 底本校勘」） |

**時間辨析（三個必須分清的年份）：**

| 時間 | 事件 | 依據 |
|------|------|------|
| 嘉祐六年（1061）十一月前後 | 蘇軾赴鳳翔府簽書判官廳公事任，至治平元年（1064）還朝 | 蘇軾本傳及年譜通說 |
| 十九年前＝約 1061–1062 | 蘇軾在岐山（岐下）見方山子從兩騎射鵲、馬上論兵 | 本文「前十九年，余在岐山」；《宋史·陳希亮傳》作「在岐下」，相合 |
| 元豐二年（1079）八月十八日下獄、十二月二十九日出獄 | 烏臺詩案 | 《宋史》本傳及諸家記載 |
| 元豐三年（1080）正月 | 赴貶途中至岐亭北二十五里，陳慥出迎，「為留五日，賦詩一篇而去」 | 蘇軾〈岐亭五首〉敘，《東坡全集》卷十四 |
| 元豐三年（1080）二月至黃州 | 抵貶所 | 《宋史》本傳；本文「余謫居於黃」 |

- 蘇軾〈岐亭五首〉敘（《東坡全集》卷十四）把這次相逢記得極清楚：「**元豐三年正月，余始謫黃州，至岐亭北二十五里，山上有白馬青蓋來迎者，則余故人陳慥季常也，為留五日，賦詩一篇而去。**」——相逢在**元豐三年正月**，地點在**岐亭北二十五里**，陳慥是騎白馬、張青蓋主動前來相迎的。〈方山子傳〉只寫「過岐亭，適見焉」的巧合，蘇軾自己的詩敘卻露出了實情：**那不是純然的偶遇，是一個知道他會路過的人，已經在路邊等著了。**
- 由元豐三年（1080）上推「十九年」，正落在嘉祐六年（1061）前後，**與蘇軾鳳翔任期的地望（岐山）完全吻合**——這是全文唯一可以精確核算的時間點。
- 同篇敘又記此後四年的往來：「凡余在黃四年，三往見季常，而季常七來見余，蓋相從百餘日也」；並記陳慥本好殺生、蘇軾作詩勸其戒殺，「季常自爾不復殺，而岐亭之人多化之，有不食肉者」；元豐七年（1084）四月蘇軾量移汝州離黃，「送者皆止慈湖，而季常獨至九江」。
- 文中「前十九年」為整數表述，實際可能是十八或十九年；**不可據以反推精確年份。**

> **「岐山」不是「岐亭」。** 前者在鳳翔府（今陝西岐山一帶），是十九年前射鵲、論兵之地；後者在黃州（今湖北黃岡麻城一帶），是眼前相逢之地。同一篇裡兩個地名各據一端，中間隔著十九年——這是全文的結構槓桿，讀錯就全篇失焦。蘇軾另有〈岐亭五首〉記陳季常，其地亦在黃州，與鳳翔之岐山無涉。

## 二、時代壓力

元豐年間，王安石變法已推行十餘年，新舊黨爭白熱化。〈方山子傳〉寫的不是變法，卻處處是變法的陰影。

| 壓力面向 | 具體內容 |
|----------|----------|
| **政治高壓** | 蘇軾因詩文獲罪，下御史臺獄（烏臺詩案）。臺諫李定、舒亶等論以死罪，賴多方營救（含已退居的王安石、章惇、曹太皇太后等）而免；最後責授黃州團練副使、本州安置、不得簽書公事——**有官銜、無職權、不准離開黃州**。 |
| **士人困境** | 進退出處兩難：投身宦海則有黨爭之禍，退隱山林則違背儒家兼濟之志。多數人兩頭落空，而〈方山子傳〉正好寫出一個「真的退成了」的樣本。 |
| **社會風氣** | 北宋中期重文輕武，文人談兵任俠已屬邊緣。「使酒好劍」「遊西山」這類少年行徑，在元豐年間的語境裡是「不合時宜」四個字的活標本。 |
| **心理壓力** | 蘇軾出獄後驚魂未定。他在黃州寫〈赤壁賦〉是後話；〈方山子傳〉寫在初到黃州、心神最不定的時候，通篇卻幾乎不提自己的委屈——**愈是不提，愈看得出來。** |

**此文的潛臺詞，是一個時代的失敗者寫另一個失敗者——而後者比他更從容。**

## 三、關鍵人物

### 1. 陳慥（字季常，號方山子、龍丘子／龍丘居士）——被寫的那個人

> 「慥」讀音依維基百科〈陳慥〉條標作 zào。坊間或見作「陳造」，屬同音假借，**本檔未查得宋代文獻用例，僅附記備考**；正文一律從底本作「陳慥」。

| 項目 | 內容 |
|------|------|
| **生卒** | **陳慥本人的生卒年不詳**（《宋史》與〈陳公弼傳〉皆無紀年；維基百科作「（？—？）」）。其父陳希亮：生於咸平三年（1000），卒於治平二年（1065）四月；享年《宋史》本傳與蘇軾〈陳公弼傳〉並作「六十四」，維基百科作「六十六」，**本檔從第一手材料作六十四，並存異說** |
| **出身** | 其先京兆（今陝西西安）人，唐廣明中遷眉州青神（今四川青神）；陳希亮第四子（蘇軾〈陳公弼傳〉：「公諱希亮，字公弼，姓陳氏，眉之青神人。其先京兆人也，唐廣明中始遷於眉」；傳末列「子四人：忱……恪……恂……慥，未仕」），與蘇軾同出眉州 |
| **官運** | 本文云「世有勳閥，當得官，使從事於其間，今已顯聞」——即當時士大夫子弟慣走的蔭補入仕之路。**陳慥終身無官，而蘇軾自己留下了原因。**〈陳公弼傳〉記陳希亮「當蔭補子弟，輒先其族人，**卒不及其子慥**」，傳末列四子，於慥獨書「**未仕**」——蔭補的名額被父親先給了族人，他便一生沒有官位。**不可把本文讀成「他曾有官而放棄」**：句中的「使」（假使）是虛擬語，說的是制度上他本可以走的那條路 |
| **與蘇軾的交誼** | 一在岐下（約 1061–1062，射鵲、馬上論兵）；一在岐亭北二十五里（元豐三年正月，陳慥騎白馬、張青蓋出迎，蘇軾留五日）。此後蘇軾居黃四年，「三往見季常，而季常七來見余，蓋相從百餘日」；元豐七年（1084）四月蘇軾量移汝州，送行者皆止於慈湖，「季常獨至九江」（以上並見〈岐亭五首〉敘）。另有詩〈寄吳德仁兼簡陳季常〉戲之，即「河東獅吼」典故所出（見下） |
| **信仰與別號** | 維基百科〈陳慥〉條轉引《蜀中廣記》等：陳慥晚年居黃州岐亭，常信佛、飽參禪學，自稱「龍丘先生」，又曰方山子；喜好賓客、蓄納聲妓。南宋·祝穆《方輿勝覽》卷五十「黃州·人物」亦載：「陳慥，字季常，寓居黃之陂亭，號龍丘子，東坡為作〈方山子傳〉」 |

**軍師提醒：** 坊間常把陳慥說成「天生的隱士」，其實他前半生是使酒好劍、用財如糞土的豪俠子弟，後半生才有庵居蔬食。〈方山子傳〉的力量正來自這個落差——**不是他從來如此，而是他曾經完全不是如此。**

### 2. 蘇軾（字子瞻）——寫的那個人

| 項目 | 內容 |
|------|------|
| **此時狀態** | 元豐三年（1080）初到黃州，任團練副使，「不得簽書公事」，形同軟禁；生活困窘，初寓定惠院，後遷臨皋亭 |
| **年齡** | 生於景祐三年十二月十九日（折算西曆為 1037 年 1 月 8 日），元豐三年約實歲 44–45（虛歲 45–46）。**本文未言及作者年齡，本檔不妄定** |
| **心理處境** | 剛從死囚牢裡出來。他一路上寫的詩文（如赴黃途中之作）都還在收拾驚魂，而〈方山子傳〉是他在黃州最早的一批文章之一 |
| **此文的投射** | **蘇軾寫陳慥，其實是在寫那個他做不到的自己。** |

### 3. 陳希亮（字公弼，1000–1065）——隱形的第三個人物

- 陳慥之父，官至太常少卿、京東轉運使，為政嚴明，《宋史》稱「嚴而不殘」。
- **他正是蘇軾在鳳翔時的頂頭上司。** 蘇軾〈陳公弼傳〉自記：「公於軾之先君子，為丈人行（按：長輩）。而軾官於風翔，實從公二年。方是時，年少氣盛，愚不更事，屢與公爭議，至形於言色，已而悔之。」——**蘇陳兩家本有世交，蘇軾在鳳翔當了他兩年屬下，還公開頂撞過他。**《宋史》本傳亦記希亮「數上章請老，不允，移知鳳翔」，與蘇軾任期相接；維基百科〈陳希亮〉條所記「府吏稱蘇軾『蘇賢良』、希亮怒曰『府判官，何賢良也』」一節，**本檔另通讀《宋史·陳希亮傳》未見此語，當是《宋史》他處或別本所記，姑存待考**。
- **兩家的淵源不止於上下屬。** 〈陳公弼傳〉開篇即云陳希亮「眉之青神人。其先京兆人也，唐廣明中始遷於眉」，與蘇軾同出眉州；蘇軾又自記其父蘇洵與陳希亮為「丈人行」的交情。陳家在洛陽另有園宅（即本文「而其家在洛陽，園宅壯麗，與公侯等」），那正是陳慥「棄不取」的家業。
- **陳希亮的「不蔭其子」是本篇最硬的一塊背景。** 〈陳公弼傳〉：「當蔭補子弟，輒先其族人，**卒不及其子慥**。」——本文〈方山子傳〉說「世有勳閥，當得官」，講的是制度上他本該有官；而事實是，那個名額被他父親讓給了族人。**陳慥的隱，不是從「有官不為」開始的，而是從「根本沒有官位」開始的**——他有的是洛陽園宅與河北田租（那是家產），沒有的是一個朝廷給的位置。
- **這層關係是讀本篇的隱形背景：** 十九年前在岐下，蘇軾是陳家的部屬晚輩；十九年後在岐亭，一個是待罪之臣，一個是山中隱者。父子兩代、十九年、兩種身分，都被壓進這 371 字裡。

### 4. 陳妻柳氏——「河東獅吼」的源頭

| 項目 | 內容 |
|------|------|
| **出現位置** | 不在本文中。蘇軾〈寄吳德仁兼簡陳季常〉詩戲之：「誰似龍丘居士賢，談空談有夜不眠。忽聞河東獅子吼，拄杖落手心茫然。」（詩題及詩句依維基百科〈陳慥〉條引錄） |
| **身分** | 維基百科稱其為河東柳氏（河東為柳姓郡望），**本名不詳**；「柳月娥」之名屬後世民間稱呼，非宋人記載 |
| **文學影響** | 「河東獅吼」「季常之癖」自此成為悍妻的代名詞 |
| **文本作用** | 與本文無直接關係，但提醒讀者：陳慥的隱居生活未必盡是灑脫。**〈方山子傳〉只寫「妻子奴婢皆有自得之意」的那一面——蘇軾寫的是他想看見的那個陳慥。** |

## 四、寫作意圖

### 核心命題：蘇軾寫陳慥，其實是在寫自己——那個他想做但做不到的人。

**一、對比結構：蘇軾 vs. 方山子**

| 面向 | 蘇軾（寫作者） | 陳慥（被寫者） |
|------|--------------|--------------|
| **處境** | 被貶，仍在官場漩渦的檔案裡 | 主動退隱，徹底出局 |
| **心境** | 憤懣、不甘、努力超脫 | 俯而不答，仰而笑 |
| **外在** | 仍是士大夫形象 | 已「毀冠服」，與樵夫無異 |
| **過去** | 同為少年意氣（一在岐下相識） | 同為少年意氣（使酒好劍，用財如糞土） |
| **現在** | 從高處跌落，仍想爬回去 | 從高處跌落，乾脆不回去了 |
| **關鍵差異** | **「我還在想，他已經不想了。」** | |

**二、方山子是蘇軾的一面鏡子**

〈方山子傳〉寫在蘇軾剛到黃州、心緒最不穩的時候。他後來在黃州寫出〈赤壁賦〉、〈念奴嬌·赤壁懷古〉等曠達之作，但那是幾年之後的事：

- 他羨慕陳慥能「皆棄不取」。
- 他知道自己做不到——洛陽園宅、河北田租，陳慥棄得掉，他棄不掉的是自己的名與志。
- 於是他用一篇文章，替那個「另一條路上的自己」立了碑。

文末一段尤為關鍵：

> 「余聞光、黃閒多異人，往往佯狂垢汙，不可得而見，方山子儻見之歟？」

陳慥已經被歸入「異人」之列；而蘇軾把最後一問留成沒有答案的推測。**他問的不是陳慥有沒有見過異人，而是：那種我做不到的活法，究竟通向哪裡？**

**三、戰略解讀：一次極端去風險化的撤退**

把人生當作一場博弈，陳慥的決策是教科書級的**風險出清**：

| 維度 | 陳慥的選擇 | 代價／收益 |
|------|-----------|-----------|
| **政治風險** | 離開官場，退入光、黃之間 | 免於黨爭傾軋 ✅ |
| **家族資本** | 「世有勳閥」而棄之，讓家族政治資本在他這一代斷裂 | 難以量化，但犧牲明確 ⚠️ |
| **人身安全** | 「不與世相聞」，等於從政治雷達上消失 | 有效 ✅ |
| **生活品質** | 庵居蔬食、環堵蕭然 | 由富樂到枯寂 ⚠️ |
| **社會身分** | 「毀冠服」「人莫識也」 | 主動選擇社會性死亡 ⚠️ |
| **精神狀態** | 「妻子奴婢皆有自得之意」「俯而不答，仰而笑」 | 文中唯一給出的正面訊號 ✅ |

蘇軾看懂了這套策略，但他做不到。他的才華、他的名聲、他對「當世」的執念，都讓他無法像陳慥那樣消失。

**四、旁證：蘇軾寫陳家的方式，就是他寫〈方山子傳〉的方式**

〈陳公弼傳〉末尾有一段自白，是理解蘇軾傳記寫作的鑰匙：「軾平生不為行狀墓碑，而獨為此文，後有君子得以考覽焉。」又說自己與陳希亮「屢與公爭議，至形於言色，已而悔之」。**一個宣稱平生不寫行狀墓碑的人，為陳家父子寫了一篇傳、又寫了一篇傳**——一篇替被他頂撞過的長輩平反，一篇替那個放棄一切的舊友留影。兩篇合看，寫的其實是同一件事：**對自己走過的路，遲到的理解。**

> **方山子是蘇軾的精神備胎——那個在人生岔路口選擇了另一條路的自己。**

## 五、文本細節中的暗線

| 原文片段 | 深層解讀 |
|----------|----------|
| 「方山子，光、黃閒隱人也。」開篇即定位 | 光州、黃州在北宋都不是通都大邑。作者一句話就把這個人放到地圖的邊上——他甚至不是「某縣某人」，而是「光、黃之間」的一個座標。 |
| 「少時慕朱家、郭解爲人，閭里之俠皆宗之。」 | 朱家、郭解是《史記·游俠列傳》所載漢代遊俠，前者「所藏活豪士以百數」，後者終以俠被誅。陳慥的少年偶像不是聖賢而是法外之徒——底本夾注亦注「俱漢時遊俠」。 |
| 「晚乃遯於光、黃間，曰岐亭。」 | 「遯」是退避之義，《易》有〈遯卦〉，與「遁」通用；底本作「遯」而不作「遁」，屬異體，非有意用經語。 |
| 「棄車馬，毀冠服，徒步往來山中。」 | 車馬與冠服是士人身分的兩件證件，一併註銷——這不是歸隱，是身分重置。 |
| 「俯而不答，仰而笑。」 | 蘇軾沒有問他為什麼退，他卻用動作回答了更大的問題。**這七個字是全篇的樞紐：該說的人不說，寫的人替他說了千言。** |
| 「此豈古方山冠之遺像乎！」 | 底本夾注引《後漢書》：「方山冠似進賢冠，以五采縠爲之。」樂人戴的冠被戴進深山，等於自願活出時代之外。（夾注原文如此，本檔未核《後漢書》原書。） |
| 「環堵蕭然，而妻子奴婢皆有自得之意。」 | 家徒四壁卻人人自得——底本夾注標「描寫隱居之樂，刻畫入情」。蘇軾用家人來背書，讓讀者相信這不是硬撐。 |
| 「今幾日耳……而豈山中之人哉？」 | 底本夾注標「得此一轉，更見悲壯」。十九年壓縮成「幾天」，是全文最狠的修辭。 |
| 「皆棄不取，獨來窮山中，此豈無得而然哉？」 | 底本夾注標「掉轉自得意句」。蘇軾自己在猜答案：一定是他得到了什麼，才放得下這些。 |

## 六、一句話總結

**方山子是蘇軾在人生最黑暗的時刻，替自己塑造的一個精神分身——那個真正放下了一切、頭也不回走入山中的人，而蘇軾自己只能站在山腳下，寫一篇傳記來紀念那個他永遠不會成為的自己。**

> 〈方山子傳〉從來不只是一篇陳慥的傳。它也是蘇軾寫給自己的、一封寄不出的信——收件人是那個敢於徹底消失的自己。

> ① **陳慥生卒年**——《宋史》無紀年，維基百科作「（？—？）」；本檔不列年份。
> ② **陳希亮享年**——《宋史·陳希亮傳》與蘇軾〈陳公弼傳〉並作「年六十四」，維基百科作「享年六十六」並系卒於 1065 年 5 月；本檔從第一手材料作六十四，並存異說。
> ③ **蘇軾與陳慥初識的時間與場合**——《宋史》僅云「在岐下，嘗從兩騎挾二矢與蘇軾遊西山」，本篇云「前十九年，余在岐山」，皆未給出年份。可確定者是：蘇軾〈陳公弼傳〉自記「軾官於風翔，實從公二年」，而〈岐亭五首〉敘稱陳慥為「故人」、本篇稱「此吾故人」，可見相識在岐亭相逢之前、且與鳳翔時期相關；惟始於何年，**待考**。舊說二人少年時即相識於眉山（兩家同出眉州、陳希亮與蘇洵有舊），**本檔未查得文獻明證，不採信、亦不寫入正文**（〈陳公弼傳〉只說兩家是「丈人行」的世交，不等於二人自幼相識）。
> ④ **陳希亮知鳳翔府與蘇軾任簽書判官的任期重疊情形**——維基百科繫陳希亮知鳳翔於嘉祐八年（1063）正月，蘇軾則自嘉祐六年（1061）十一月前後任鳳翔簽書判官，〈陳公弼傳〉稱蘇軾「實從公二年」。若射鵲一事在 1061–1062 年，其時陳希亮是否已知鳳翔，**待考**（舊註：此點不影響「前十九年」的計算，只影響陳慥當時何以在岐下）。
> ⑤ **本篇確切寫作年月**——文中只說「余謫居於黃，過岐亭，適見焉」，未記年月。相逢已確知在元豐三年正月（〈岐亭五首〉敘），但〈方山子傳〉寫於相逢之後的何月，**無據可查，本檔不敢指定月日**。
> ⑥ **陳慥居岐亭的年數**——維基百科〈陳慥〉稱蘇軾過訪時陳季常「居岐亭五年矣」，**本檔未查得此語所出原書**；而〈岐亭五首〉敘反而記元豐三年時陳慥尚好殺生、經蘇軾勸戒始改，兩說不可並存，故本檔兩者皆不寫入正文。
> ⑦ **岐亭今地**——宋屬黃州，維基百科繫為「黃州（今湖北黃岡市黃州區）之岐亭」；今一般對應湖北黃岡麻城市岐亭鎮一帶。**本檔只寫「今湖北黃岡麻城一帶」，不指定鄉鎮級地望。**
