# 〈愚溪詩序〉背景資料

> 軍師曰：此乃被貶之人以「愚」為刀，反刺世道之作。

---

## 一、座標定位

| 項目 | 內容 |
|------|------|
| **時間** | 唐憲宗元和五年（810）前後（**確年不確定**，考辨見第五節「底本校勘」） |
| **地點** | 永州（今湖南省永州市）冉溪（愚溪）畔 |
| **作者** | 柳宗元（773–819），字子厚，河東解縣（今山西運城）人，世稱柳河東、柳柳州 |
| **背景事件** | 永貞革新（805 年）失敗，柳宗元被貶為永州司馬員外置同正員 |
| **文體** | 序文——為自作的組詩《八愚詩》所寫的序。《八愚詩》至宋代已亡佚（宋註本明言「今逸之」），今僅存此序 |
| **出處** | 《古文觀止》卷九·唐宋文，卷九第七篇（前接柳宗元〈梓人傳〉，後接〈永州韋使君新堂記〉） |

柳宗元於永貞元年（805 年）被貶永州司馬，名為州佐，實為編外的閒散安置。元和五年左右，他在城外的冉溪邊購地築室，將這條「名莫能定」的溪改名「愚溪」，並以此為中心，把丘、泉、溝、池、堂、亭、島一一冠上「愚」字，寫下《八愚詩》及這篇序——為自己的「愚人」身分立傳。詩已不存，序卻流傳下來，於是我們讀到的，其實是一組失傳詩作的說明書。

## 二、時代壓力——永貞革新的失敗與文人的憤怒

### 永貞革新始末

貞元二十一年（805 年）正月，唐德宗去世，太子李誦即位，是為順宗。順宗任用王叔文、王伾、柳宗元、劉禹錫、韋執誼等人推行改革，史稱「永貞革新」：

- **打擊宦官勢力**（罷「宮市」、放還「五坊小兒」）
- **抑制藩鎮**（劉闢奉韋皋之意入朝，「求都領劍南三川」，王叔文怒而拒之，事見《資治通鑑》卷236）
- **整頓財政**（停罷鹽鐵使月進等進獻、量入為出）

然而順宗本人中風失語，革新缺乏穩固的權力基礎。同年六月，王叔文因母喪去職，決策中樞瓦解；七月二十八日順宗同意太子監國，八月四日下詔禪讓，八月九日憲宗即位。順宗在位僅半年餘（正月二十六日即位，八月四日禪讓），而據史家考證，二王等人**實際執政只有一百四十六天**（此為「實際執政」之數，非順宗在位日數；來源與保留見第五節存疑說明③）。革新派隨即被清算：

- 王叔文貶渝州司戶，次年（元和元年，806 年）賜死
- 王伾貶開州司馬，到貶所即病死（以上並見《資治通鑑》卷236）
- 同年（永貞元年）十一月，八人同遭貶謫，是為「二王八司馬」：韋執誼（崖州）、韓泰（虔州）、韓曄（饒州）、**柳宗元（永州）**、劉禹錫（朗州）、陳諫（台州）、凌准（連州）、程異（郴州），皆為遠州司馬。據《舊唐書·憲宗本紀》，八人「初貶刺史，物議罪之，故再加貶竄」；柳宗元即由邵州刺史再加貶為永州司馬，此後在永州度過十年。

### 貶謫後的生存狀態

柳宗元在永州的處境極為艱困：

- **政治身份**：他的正式官銜是「守永州司馬員外置同正員」——「員外置同正員」是編制外的員額，名為州佐，實無職掌。柳宗元自己在〈與顧十郎書〉的署名前就是這樣寫的。至於「不得干預州政」一類說法，本檔未能查到直接的敕令原文，**標為不確定**。可以確定的是他長期處於「罪臣待罪」的狀態：元和元年（806）八月，朝廷明詔「左降官韋執誼、韓泰、陳諫、柳宗元、劉禹錫、韓曄、淩准、程異等八人，**縱逢恩赦，不在量移之限**」（《舊唐書·憲宗本紀》卷14）。
- **居住條件**：初到永州無官舍可住，寄居城西龍興寺；元和四年（809）在法華寺西亭築亭；元和五年左右才遷居冉溪（愚溪）築室。永州又多火災，柳宗元〈與楊京兆憑書〉自述「**永州多火災，五年之間，四為天火所迫。徒跣走出，壞牆穴牖，僅免燔灼。書籍散亂毀裂，不知所往**」——他所說「多次遷徙」，指的正是這種被迫的流離。
- **心理狀態**：元和元年（806）五月十五日，母親盧氏病逝於永州零陵佛寺（〈先太夫人河東縣太君歸祔誌〉）；元和五年（810）四月三日，十歲的女兒和娘又死於永州（〈下殤女子墓磚記〉）。這兩次死亡夾出了〈愚溪詩序〉的寫作時間——母親、女兒相繼埋骨貶所，他自己則多病，〈寄許京兆孟容書〉自述「**殘骸餘魂，百病所集，痞結伏積，不食自飽**」，〈與楊京兆憑書〉亦云「一二年來，痞氣尤甚，加以眾疾」。
- **社會關係**：親友斷絕往來，鄉黨視為異類。〈寄許京兆孟容書〉開篇即說「伏念得罪來五年，未嘗有故舊大臣肯以書見及者。何則？**罪謗交積，群疑當道**，誠可怪而畏也」。

正是在這樣的絕境之中，柳宗元轉向山水，以筆墨對抗世界。

## 三、關鍵人物與命名對象

### 核心人物：柳宗元（773–819）

字子厚，河東解縣人，唐宋八大家之一。永貞革新失敗後貶永州司馬（805–815 在永州），在永州寫下〈永州八記〉、〈捕蛇者說〉、〈三戒〉、〈愚溪詩序〉等代表作；後改任柳州刺史，卒於任所，故又稱柳柳州。

**在本篇中的角色**：他既是敘事者，也是被命名的對象。全文自稱「余」，卻把最主要的篇幅讓給一條溪——溪的來歷、溪的罪狀、溪的美、溪的名字。柳宗元本人只藏在「適類於余」四個字裡。這是本文最經濟的一手：不必自辯，只要替溪辯護到底，讀者自然會把判決移回人身上。

### 「八愚」命名體系

| 名稱 | 原文依據 | 說明 |
|------|---------|------|
| **愚溪** | 「故更之為愚溪」 | 原名冉溪／染溪（「名莫能定」），柳宗元改稱愚溪。全篇軸心 |
| **愚丘** | 「愚溪之上，買小丘，為愚丘」 | 愚溪上游購得的小丘 |
| **愚泉** | 「自愚丘東北行六十步，得泉焉，又買居之，為愚泉。愚泉凡六穴，皆出山下平地，蓋上出也」 | 在**愚丘**東北六十步處購得的泉水，六穴自平地湧出。方位須注意：六十步是愚丘到愚泉的距離，不是愚溪到愚丘 |
| **愚溝** | 「合流屈曲而南，為愚溝」 | 愚泉六穴合流後曲折南行，即為愚溝 |
| **愚池** | 「遂負土累石，塞其隘，為愚池」 | 挑土壘石、堵塞狹窄處而成的水池 |
| **愚堂** | 「愚池之東，為愚堂」 | 愚池東邊的堂。八愚之一，卻最常被漏列 |
| **愚亭** | 「其南，為愚亭」 | 愚池南邊的亭。原文未說他「觀水、讀書、垂釣」於此，此類細節係後人想像 |
| **愚島** | 「池之中，為愚島」 | 愚池中央的小島 |

八愚加上一句總收「嘉木異石錯置，皆山水之奇者，以余故，咸以愚辱焉」——這不是單純的山水題詠，而是一套**系統性的身份宣示**：他把自己所觸及的一切，都拉進「愚」的陣營，以集體自貶的方式，反諷那個將他逐出的所謂「聰明」世界。而「以余故」三字是全篇最重的一筆：山水無辜，是他把罪名帶給了山水。

### 典故人物

| 人物 | 出處 | 在文中的作用 |
|------|------|-------------|
| **甯武子** | 《論語·公冶長》：「甯武子，邦有道則知，邦無道則愚。其知可及也，其愚不可及也。」春秋衛國大夫 | 柳宗元取其「邦無道則愚」，判為「智而為愚者也」——是裝的，不算真愚 |
| **顏子（顏回）** | 《論語·為政》：「吾與回言終日，不違，如愚。退而省其私，亦足以發，回也不愚。」孔子弟子 | 柳宗元取其「終日不違如愚」，判為「睿而為愚者也」——同樣是裝的。**注意**：《論語》原句結論是「回也不愚」，柳宗元是反用經典 |
| **愚公谷的老公** | 劉向《說苑》卷七〈政理〉：齊桓公逐鹿入山谷，問老公谷名，答「為愚公之谷」，因「以臣名之」 | 提供「以人名谷」的先例，讓柳宗元的命名行動取得正當性；《說苑》篇末孔子更說「猶有以智為愚者也」——正是本文「智而為愚」的遠祖 |

## 四、寫作意圖——表面自嘲，實則反諷

### 表面的姿態：自稱愚人

> 「余以愚觸罪，謫瀟水上……故凡為愚者，莫我若也。」

柳宗元在文中把自己與古代愚者相比，結論是「沒人比我更愚」。表面上全盤接受世人對他的評價——你被貶，就是因為你愚。

### 深層的結構：以愚為鏡，照見天下

打開文本，反諷密布：

1. **溪本不愚，人強名之**——大自然無所謂智愚，是人的遭遇賦予了山水意義。溪之所以為愚溪，不是因為溪愚，而是因為住溪邊的人「愚」。「以余故，咸以愚辱焉」——他明白承認是他把這個名字強加給山水的。
2. **智者裝愚，皆非真愚**——文中舉甯武子「邦無道則愚」、顏回「終日不違如愚」兩位智者（皆出《論語》），判語是「皆不得為真愚」。這一步極關鍵：聖人門下的裝愚者都被排除，真愚的位子就空了出來。
3. **真愚的位子由他自己填上**——「今余遭有道，而違於理，悖於事，故凡為愚者，莫我若也」。「遭有道」三字是反話的引信：盛世無冤，他卻在此時因「違理悖事」獲罪。他不在字面上說「當今無道」，但讀者會自己算出來。
4. **愚溪之樂**——溪水「清瑩秀澈，鏘鳴金石」，能「漱滌萬物，牢籠百態」。一個真正愚笨的溪，怎會有如此神采？這分明是作者把自己的才華與傲骨投射到了溪水之上。

### 一句話總結

> **「你說我愚，我就愚給你看」——柳宗元將一溪山水全數冠以「愚」名，以極端自嘲的外衣，包裹著對貶謫命運最凌厲的諷刺與對自身高潔才華最驕傲的宣示。**

### 戰術定位

〈愚溪詩序〉的寫作策略，是一記標準的**反手刀**：

| 層面 | 對手 | 柳宗元的回應 |
|------|------|-------------|
| 政治面 | 朝廷以「罪名」加身 | 我以「愚名」自居，你的罪名我不認，我的愚名我認 |
| 道德面 | 世人以「失勢」輕我 | 我承認自己愚——但甯武子、顏回也愚，你敢說他們不賢？ |
| 審美面 | 環境以「荒僻」困我 | 我把荒溪變為愚溪——從此這條溪、這丘、這泉，都帶著我的印記 |

這不是投降，而是**用對方的邏輯反過來打對方的臉**。你貶我是因為我愚？好，我就把這條溪叫愚溪，讓這條溪世世代代提醒後人——是誰把一個真正乾淨的人逼到這裡來的。

> **存疑說明**：
> ① **繫年**：本檔標「元和五年（810）前後」，但確年不確定。宋註本於題下註：「公嘗與楊誨之書云：『方築愚溪東南為室。』而此言丘泉溝池堂溪亭島皆具。序當作於書之後。」而〈與楊誨之書〉據同書卷33註作於元和五年十一月（註以《憲宗紀》元和五年詔「來年正月藉田」推定）。若兩註皆可信，此序既在該書之後、其時八愚又「皆具」，則可能晚至元和五年末至六年（811）之間；一般選本題解則逕繫於元和五年。本檔兩存而不強斷。
> ② **「不得干預州政」**：唐代貶官任州司馬者多為員外安置、不與州政，本檔據〈與顧十郎書〉的自署銜名可證其為「員外置同正員」；但「敕令不得干預州政」這句具體表述，本檔未查到直接詔令原文，故正文已標為不確定。八司馬「縱逢恩赦，不在量移之限」則為詔令明載。
> ③ **一百四十六天**：此數指「二王八司馬實際執政」的日數，**不等於順宗在位日數**（順宗自貞元二十一年正月二十六日即位至八月四日下詔禪讓，約六個多月）。前稿寫成「革新僅維持一百四十六天」，易生誤解，已改為上述表述。惟本檔僅得一個二手來源（馬立誠《「二王八司馬」的146天》，[愛思想](https://www.aisixiang.com/data/22047.html)）轉引「史學家漆俠考證」，未取得漆俠原始考證文的精確起訖日；**此數標為不確定**，僅作參考。
> ④ **愚溪方位里距**：柳宗元自述「灌水之陽有溪焉，東流入於瀟水」，吳氏夾注僅言「灌、瀟二水，在永州府城外」。「在府城西一里」一類里距僅見於後出方志引文，本檔未取得可核原書，不寫入正文。
> ⑤ **柳宗元卒日兩說**：韓愈〈柳子厚墓誌銘〉作「子厚以元和十四年**十一月八日**卒，年四十七」（[維基文庫](https://zh.wikisource.org/wiki/柳子厚墓誌銘)；夾注本《古文觀止》卷八 part144 同），《舊唐書》卷160本傳作「元和十四年**十月五日**卒，時年四十七」（[維基文庫](https://zh.wikisource.org/wiki/舊唐書/卷160)）。韓愈為柳宗元摯友且撰墓誌，一般從其說；本檔於正文僅用「773–819」，不採單一卒日。享年「四十七」為虛歲，今人換算實歲為四十六。

## 六、軍師總評

> **座標：永州冉溪（愚溪）畔，元和五年（約810）前後；**
> **敵情：永貞革新失敗，宦官當道，朝綱傾頹；**
> **己方戰力：一介罪臣，一支禿筆，一溪清水；**
> **戰術：以「愚」為盾，化貶謫為風景；以「愚」為矛，刺穿世道虛偽。**
> **結論：愚溪不愚，愚的是這個容不下聰明人的世道。柳宗元贏了——千年之後，誰還記得那些貶他的人叫什麼名字？而愚溪，永遠是愚溪。**
