# 〈種樹郭橐駝傳〉背景資料

> 軍師曰：讀此文，莫被「種樹」二字騙了。全篇四百七十三字，前三段（命名、種樹之道、他植者之失）共三百一十七字，後兩段（官理、收束）只有一百五十六字——但前面那三百多字，全是為後面那一百多字鋪的路。

---

## 一、座標定位

| 項目 | 定位 |
|------|------|
| **典籍** | 柳宗元《柳河東集》卷十七·傳；《全唐文》卷五九二、《柳州文鈔》卷五亦收 |
| **選集** | 《古文觀止》卷九·**唐宋文**第五篇（全書第 147 篇；前接〈捕蛇者說〉，後接〈梓人傳〉） |
| **體裁** | 「傳」——人物傳記體，實為寓言性質的政論散文。全篇以問答推進，虛構人物承載真實議論 |
| **作者** | 柳宗元（773–819），字子厚，祖籍河東解縣（今山西永濟），世稱柳河東、柳柳州。唐宋八大家之一，與韓愈並稱「韓柳」 |
| **寫作時間** | 通說繫於貶謫永州期間（約元和年間，806–815）。**作年無確考**，另有學者因文中對長安豪家、果農行情之熟悉，推測可能作於其任職長安之時（貞元末） |
| **故事空間** | 長安城西豐樂鄉（郭橐駝的鄉里）；鏡頭外則是柳宗元所在的永州（今湖南永州零陵區）——一個在廟堂之側，一個在瘴癘之鄉 |
| **關鍵人物** | 郭橐駝（主角，真實與否存疑）、問者、他植者（隱喻）、長人者與吏（隱喻）、柳宗元（作者） |
| **原文起訖** | 「郭橐駝，不知始何名。」至「傳其事以為官戒也。」（全篇入選，無刪節） |

**軍師點位**：這篇文章的地圖有兩層。表層是長安西郊的一座果園——一個駝背老頭在那裡種樹，種得比誰都好。裡層是永州的一間佛寺——一個被貶的官員在那裡回想他見過的官吏，以及他們如何用一紙接一紙的命令，把百姓的日子絞碎。文章的殺傷力全在這個落差上：郭橐駝從頭到尾只承認自己是個種樹的（「我知種樹而已，官理非吾業也」），可他講的每一句種樹的道理，都精準地打在「長人者」身上。

## 二、時代壓力

### 2.1 中唐的病：藩鎮、苛稅、繁令

安史之亂（755–763）以後，唐帝國的骨架就沒再接回去過：

- **藩鎮割據**：河朔三鎮形同獨立，中央號令出不了關中。地方節度使自行任官、自行徵稅，中央財政只能靠江淮漕運苦撐。
- **賦稅苛重**：德宗建中元年（780）行兩稅法，本想簡化稅制，實行下來卻因「量出制入」而層層加碼，加上鹽鐵專賣與種種附加，百姓負擔不減反增。
- **政令繁碎**：中央要向地方證明自己還在管事，最方便的方式就是不停地頒令、考核、催辦。對百姓而言，這意味著沒有一天不被「促爾耕，勖爾植，督爾穫」包圍。

這三件事疊在一起，正是柳宗元筆下「長人者好煩其令，若甚憐焉，而卒以禍」的現實底本。要注意「**若甚憐焉**」四字——柳宗元批判的從來不是貪官酷吏的惡意，而是**自以為在做好事的干預**。這比單純的貪暴更難反駁，也更難阻止。

### 2.2 永貞革新與二王八司馬

柳宗元二十一歲（貞元九年，793）中進士，此後累官至監察御史裡行、禮部員外郎，是長安政壇上青壯一輩的佼佼者。

- 貞元二十一年（805）正月，德宗崩，順宗即位。順宗在東宮時即中風失音，朝政由王叔文、王伾主導。
- 王叔文集團拉攏柳宗元、劉禹錫等新進之士，推行一連串革新：罷宮市、禁五坊小兒、貶逐貪吏、試圖削奪宦官兵權與藩鎮勢力。史稱「永貞革新」。
- 改革歷時不過數月。宦官俱文珍等聯手逼順宗內禪，八月憲宗即位，政局急轉。
- 九月，柳宗元貶邵州刺史；十一月，再貶永州司馬。同案遭貶者，後世合稱「二王八司馬」（二王指王叔文、王伾；八司馬指柳宗元、劉禹錫等八人）。

**注意**：這場改革常被後人比附為「百日維新」，但「百日維新」是清末戊戌變法（1898）的專稱，兩者性質、時代、結局皆不同，不宜混用；永貞革新歷時不過數月即告瓦解。

### 2.3 柳宗元的永州十年

- **官職有名無實**：司馬是州刺史的佐官，員外置同正員，在唐代是安置貶官的閒職。柳宗元在永州「不得預政事」，等於被剝奪了所有的施政可能。
- **家庭打擊**：母親盧氏隨他南下，元和元年（806）五月十五日病逝於永州零陵佛寺，年六十八（見柳宗元〈先太夫人河東縣太君歸祔誌〉）。他連歸葬都做不到，只能「銜哀待刑」。
- **身體與精神**：永州卑濕炎熱，柳宗元屢病；同時「被貶官員上書論政即是自尋死路」，他失去了直接議政的管道。
- **寫作的出口**：他轉向山水（〈永州八記〉）、寓言（〈三戒〉〈蝜蝂傳〉）與人物傳（本篇、〈梓人傳〉、〈宋清傳〉）。**散文成了他唯一的發言方式**。
- **結局**：元和十年（815）正月奉召赴京，三月又出為柳州刺史；元和十四年（819）卒於柳州任上，年四十七。

**軍師研判**：柳宗元的處境是「有話不能直說，但非說不可」。直接論政——找死；完全不說——憋死。他的解法是**把批評藏進一個種樹老人的日常閒談裡**，讓郭橐駝說出他不敢說的話，再讓問者替讀者說出結論。這一招的厲害之處在於：通篇沒有一句可以被指為「訕上」的話，卻讓每個做官的人讀完都坐立難安。

## 三、關鍵人物

### ● 郭橐駝 —— 全篇之眼

| 屬性 | 分析 |
|------|------|
| **身分** | 長安城西豐樂鄉的職業種樹人。無名無姓，因佝僂病而背部隆起，被鄉人叫作「駝」 |
| **資料真實性** | **存疑**。台灣高中國文課本謂「後世學者認為應是柳宗元虛構其人，藉以說理」；亦有主張其人實有、柳宗元為之立傳者。本檔並陳二說，不強斷 |
| **技術** | 所種之樹「或遷徙，無不活，且碩茂，蚤實以蕃」；「他植者雖窺伺效慕，莫能如也」 |
| **核心心法** | 「能順木之天，以致其性焉爾」 |
| **性格** | 坦然（「甚善！名我固當」）、自知（「橐駝非能使木壽且孳也」）、有分寸（「其蒔也若子，其置也若棄」） |

**軍師評**：郭橐駝是中國文學史上最不像『老師』的老師。他沒有任何身分加持——不是隱士，不是高僧，不是致仕的官員，只是一個身體有殘缺、靠手藝吃飯的匠人。柳宗元選他當代言人，本身就是一種政治表態：**最有資格談「養人」的，不是廟堂上的袞袞諸公，而是田埂上那個懂得「勿動勿慮，去不復顧」的老種樹人。**

### ● 柳宗元 —— 借他人酒杯

| 屬性 | 分析 |
|------|------|
| **身分** | 被貶永州的戴罪之臣，本篇的觀察者、記錄者與審判者 |
| **歷史定位** | 唐宋八大家之一，與韓愈同為唐代古文運動的領袖；寓言與山水遊記的成就尤高（〈三戒〉、〈永州八記〉） |
| **戰術選擇** | 借一個駝背種樹人的故事，層層轉喻，直指朝廷用人行政之弊 |
| **巧妙之處** | 全篇「若無意於為文」——彷彿只是在記錄一個種樹老人的閒談，最後輕巧一句「傳其事以為官戒也」，致命一擊 |

**軍師評**：柳宗元沒有讓郭橐駝慷慨陳詞。相反地，他讓郭橐駝一再退讓——「官理非吾業也」「吾又何能為哉」「其亦有類乎」——退到不能再退，才把那段差役吆喝原封不動地搬出來。這是最高明的控訴方式：**不下判詞，只呈證據。** 篇末吳楚材評為「語極冷峭」，指的正是這種不動聲色的狠。

### ● 「愛之太殷」的他植者與「好煩其令」的長人者 —— 一體兩面

| 屬性 | 分析 |
|------|------|
| **行為（果園版）** | 旦視而暮撫，已去而復顧；甚者爪其膚以驗其生枯，搖其本以觀其疏密 |
| **行為（官場版）** | 好煩其令，若甚憐焉；旦暮，吏來而呼曰：「官命促爾耕，勖爾植，督爾穫……」鳴鼓而聚之，擊木而召之 |
| **共同心理** | 自以為非常用心、非常關愛 |
| **共同結果** | 「雖曰愛之，其實害之；雖曰憂之，其實讎之」——樹「性日以離」，民「病且怠」 |

**軍師評**：這兩組人其實是同一種人。柳宗元用了一個極精準的對應：**種樹者抓樹皮、搖樹根，官吏敲鼓、擊木、下命令**——動作不同，邏輯完全一樣，都是「我必須做點什麼，才能證明我在乎」。文中「若甚憐焉」四字最誅心：他們不是壞人，他們只是受不了「什麼都不做」。而柳宗元的診斷是——**對於天性，最好的照護就是不打擾。**

## 四、寫作意圖

### 4.1 表面是種樹指南，實際是政治說明書

全篇 473 字，結構上是嚴格的「三段論」：

1. **正例**（郭橐駝）：順木之天 → 無不活、碩茂、蚤實以蕃。
2. **反例**（他植者）：愛之太殷、憂之太勤 → 木之性日以離。
3. **推論**（長人者）：好煩其令、若甚憐焉 → 民病且怠。

而這條推論線不是柳宗元自己拉出來的——是由「問者」問出來的（「以子之道，移之官理，可乎？」），再讓郭橐駝用一句「則與吾業者，其亦有類乎」輕輕帶過。**作者全程隱身，結論由讀者自己得出**，這是本文在技術上最高明的地方。

### 4.2 思想譜系：從老子的「烹小鮮」到莊子的「順物自然」

「順木之天，以致其性」不是柳宗元的發明，它有清楚的道家來源：

- **《老子》第六十章**：「治大國若烹小鮮。」——治理大國如同煎小魚，翻動得太勤，魚就碎了。這正是「勿動勿慮，去不復顧」的政治版。
- **《莊子·應帝王》**：「汝遊心於淡，合氣於漠，**順物自然而無容私焉，而天下治矣**。」（無名人答天根問「為天下」之語；維基文庫本「無」作「无」，係異體）——「順物自然」四字，幾乎就是「順木之天」的祖本。
- 需辨正一處常見誤植：「**無為而治**」一語出自《論語·衛靈公》（「無為而治者，其舜也與」），非莊子語；談莊子的無為，宜引《莊子》「順物自然」等原文。

柳宗元的獨創之處，不在哲學，而在**翻譯**：他把「治大國若烹小鮮」這類鑲在經典裡的格言，翻譯成一個種樹農民能說、能懂的日常經驗。哲學不坐在書齋裡，而是站在田埂上。

### 4.3 為何要用寓言：一個被貶者的發言策略

柳宗元不是消極無為的隱士——他是永貞革新的積極參與者，一生都在謀求「有為」。他反對的不是治理，而是**無意義的干預**。這一點必須分清楚，否則會把本文讀成一篇反對一切施政的檄文。

那麼為什麼要用「傳」這種文體？因為：

1. **可以虛構**：寓言人物不必真有，也就不必有人對號入座，卻又人人可以對號入座。
2. **可以借嘴**：郭橐駝是平民，他說「官命促爾耕」只是抱怨；柳宗元若自己說，就是訕上。
3. **可以冷收**：以一篇「為小人物立傳」的文章收尾，殺傷力遠大於一篇正式的奏議。

### 4.4 修辭與用字

- **明喻**：「其蒔也若子，其置也若棄」——用兩個「若」把抽象的「管／不管」譯成育子與丟棄，分寸立現。
- **排比**：「其本欲舒，其培欲平，其土欲故，其築欲密」四句如口訣；「官命促爾耕，勖爾植，督爾穫，蚤繰而緒，蚤織而縷，字而幼孩，遂而雞豚」由三字遞增為四字，句式愈拉愈長，模擬差役連珠炮式的催逼。
- **對偶兼對比**：「雖曰愛之，其實害之；雖曰憂之，其實讎之」——「愛／害」「憂／讎」兩對反義詞工整對舉，是本文最著名、也最無法反駁的兩句。
- **反問（反詰）**：「又何以蕃吾生而安吾性邪？」——前有「輟飧饔以勞吏者，且不得暇」的事實鋪墊，此問不是修辭，是控訴。
- **一字立骨**：篇中「順」與「擾」兩股力量互相拉扯。郭橐駝「順木之天」，他植者與長人者則以「愛」「憂」「令」相擾——文章從頭到尾都在寫這一組對抗。

> **校勘結論**：全篇逐字核對，與《古文觀止》通行本（夾注本）一致，**無誤字**。使用者指定複核的兩句名句用字確認如下——
> ①「**順木之天，以致其性**」：底本作「能順木之天，以致其性焉爾」，八字用字無誤（不作「順木之性」，亦不作「以致其性也」）。
> ②「**雖曰愛之，其實害之**」：底本作「雖曰愛之，其實害之；雖曰憂之，其實讎之」，用字無誤（「害」「讎」皆從底本）。
>
> **存疑（不確定處，僅此二項）**：
> ① **寫作年代無確考**。通說繫於永州時期（約元和年間），但亦有學者據文中對長安之熟悉，推測作於長安任職時；本檔採通說而不作斷語。又柳宗元抵達永州任所的具體時日，史無明文（一般繫於永貞元年十一月貶命之後），本檔故僅記「805 年十一月再貶永州司馬」，不強斷到任年月。
> ② **郭橐駝是否實有其人，學界無定論**（虛構說 vs 實有說），本檔並陳二說。

---

## 六、一句話總結

> **一個連名字都沒有的駝背種樹人，用「勿動勿慮，去不復顧」八個字，替柳宗元對整個中唐的官僚體系下了判詞——最好的治理不是管得更好，而是懂得放手。**
