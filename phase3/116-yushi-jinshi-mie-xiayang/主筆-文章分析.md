>
> 本檔案由 @hermes_agent 主筆

## 1. 分段大意

> 分段引文以《古文觀止》卷三通行本（夾注本）為底本，標點從底本；字數為程式實測。

**第一段：疑問的提出——虞無師為何稱「師」？**

> 非國而曰滅，重夏陽也。虞無師，其曰師，何也？以其先晉，不可以不言師也。其先晉何也？爲主乎滅夏陽也。

穀梁傳開篇不敘事，直接從經文書法提出兩個問題：夏陽不是國家，經文為什麼用「滅」字？（因為重視夏陽。）虞國根本沒有出兵，經文為什麼寫「虞師」？為什麼把虞國排在晉國前面？（因為虞國對滅夏陽負主要責任。）這個看似詞語學的疑問，實則是最尖銳的倫理追問。此段 40 字。

**第二段：夏陽的戰略地位——塞邑之重**

> 夏陽者，虞、虢之塞邑也，滅夏陽而虞、虢舉矣。

解釋夏陽這個城邑的特殊性：它是虞、虢兩國邊界上的要塞。拿下夏陽，兩國便同時陷於必亡之地。這是穀梁傳第一次點明虞國並非單純的旁觀者——被滅的城邑夾在你們兩國之間，你怎麼可能置身事外？此段 17 字，是全文最短、也是全篇地理論證的支點。

**第三段：荀息獻計——借路的心智博弈**

> 虞之爲主乎滅夏陽，何也？晉獻公欲伐虢，荀息曰：「君何不以屈產之乘、垂棘之璧，而借道乎虞也？」公曰：「此晉國之寶也，如受吾幣，而不借吾道，則如之何？」荀息曰：「此小國之所以事大國也。彼不借吾道，必不敢受吾幣，如受吾幣，而借吾道，則是我取之中府而藏之外府、取之中廄而置之外廄也。」

晉獻公欲伐虢，荀息獻計以寶馬美玉為餌借道。獻公捨不得寶物，擔心虞國收了禮卻不借路；荀息安撫他：這是小國事大國的本分，虞國不借路就不敢受禮，收了禮就等於把寶物從內庫搬到外庫暫存——遲早拿得回來。這把虞公的「獲得感」還原成「暫時保管」，精準利用虞公的貪婪與短視。此段 112 字，是全文最長的一段，全篇的計謀都由此展開。

> **注意**：本段對話據《左傳》繫於魯僖公二年（前 658），是**第一次**借道；《左傳·僖公五年》另有「晉侯**復**假道於虞以伐虢」，宮之奇再次進諫不聽、遂以其族行，該年十二月晉滅虢並回師襲虞。底本《古文觀止》把兩次借道的敘事壓縮在一起，故「宮之奇兩諫」「獻公亡虢五年」等語須還原到兩個年份上讀。

**第四段：荀息料定宮之奇——精準的人物分析**

> 公曰：「宮之奇存焉，必不使受之也。」荀息曰：「宮之奇之爲人也，達心而懦，又少長於君。達心則其言略，懦則不能彊諫，少長於君，則君輕之。且夫玩好在耳目之前，而患在一國之後，此中知以上乃能慮之，臣料虞君、中知以下也。」

獻公仍顧忌宮之奇會壞事。荀息一語道破：宮之奇心裡明白但說話簡要、點到為止，性格懦弱不能強諫，又與虞公自幼同長、不被虞公看重——三條原因注定諫言無效。更狠的是他對虞公的判斷：寶物在眼前、禍患在多年之後，只有中智以上的人才會慮及，而虞公「中知以下」。一場借道，未行已勝。此段 86 字。

**第五段：虞公借道，宮之奇兩諫不聽**

> 公遂借道而伐虢。宮之奇諫曰：「晉國之使者，其辭卑而幣重，必不便于虞。」虞公弗聽。遂受其幣而借之道。宮之奇又諫曰：「語曰：『脣亡則齒寒。』其斯之謂與。」挈其妻子以奔曹。

宮之奇先從使者「辭卑幣重」的反常態度推斷必有陰謀，虞公不聽；再以「唇亡齒寒」點破虞、虢唇齒相依的地緣邏輯，虞公仍不聽。諫言兩度碰壁，宮之奇挈妻攜子奔曹——這是智者對不可救藥之君的絕望告別。此段 65 字。

**第六段：結局——璧猶是也，馬齒加長**

> 獻公亡虢五年，而後舉虞。荀息牽馬操璧而前曰：「璧則猶是也，而馬齒加長矣。」

荀息牽馬操璧上前，只說一句：璧還是那塊璧，馬齒卻加長了。全文最犀利的一筆——虞公為了這塊璧、這匹馬出賣國家，最後什麼也沒得到。此段 30 字，收得極冷極快。

> **「五年」的時序**：《左傳·僖公五年》記晉侯復假道伐虢、同年十二月滅虞，《公羊傳》作「還，四年，反取虞」，穀梁傳作「五年而後舉虞」——三傳所指其實都是魯僖公五年（前 655）這一年的兩次行動，而非滅虢之後再等五年（見第 5 節考辨）。

## 2. 寫作技巧分析

### 穀梁傳的概念分析法——從名詞到責任

本文不同於一般歷史敘事，其核心寫作手法是**概念分析**——從經文中一個詞的用法入手，推導出倫理判斷。穀梁傳像是春秋時代的法學家，他在做的不是講故事，而是「名實之辨」：

| 概念 | 經文用法 | 穀梁傳的分析 |
|:----:|:---------|:------------|
| **滅** | 「滅夏陽」 | 夏陽不是國家卻用「滅」字——重夏陽也，因為夏陽的得失攸關兩國存亡 |
| **師** | 「虞師」 | 虞國沒有出兵，經文卻稱「師」——因為它排在晉國之前，不能不稱之為「師」 |
| **先晉** | 「以其先晉」 | 小國序於大國之上——經文的排序本身就是一種褒貶 |
| **爲主** | 「爲主乎滅夏陽」 | 虞國對滅夏陽負主要責任——借道給晉，無異於親自主導滅虢 |

### 「爲主乎滅夏陽」的責任歸屬分析——現代法律視角的對照

穀梁傳最精彩的論證，是把責任問題還原到經文的**書法**上：

> **「其先晉何也，爲主乎滅夏陽也。」**

虞國沒有出兵，經文卻把「虞師」寫在「晉師」之前——穀梁傳由此推導出一個嚴苛的結論：虞國不是被動的借道者，而是「爲主」——滅夏陽的**主要責任人**。

- 出兵的明明是晉國，經文卻以虞為先——書法的次序，暗藏責任的輕重
- 「爲主」二字，把虞公從「旁觀者」重新定性為「主導者」
- 借道給晉軍去攻打自己的鄰國，這個動作本身就消解了中立性

**用現代法律概念來翻譯：借路給人去殺人，就是幫助犯。你不一定要親手殺人，只要你提供了作案的通道、為罪犯創造了條件，你就是共犯。穀梁傳早在兩千多年前，就用「爲主乎滅夏陽」六個字，完成了同一場歸責論證。**

這是穀梁傳對整個事件的核心判斷：虞公以為自己只是一個中立的第三方、一個被動的旁觀者——但「先晉」與「爲主」的書法告訴你，當你把自己的國土交給別人去攻擊你的鄰居時，你已經不是旁觀者了。

### 荀息的心理戰術分析

荀息說服晉獻公的過程本身也是一場精彩的心理分析。他用一連串環環相扣的論證說服了獻公：

| 論證步驟 | 內容 | 策略 |
|:---------|:-----|:-----|
| **第一步** | 虞公一定會接受禮物，因為他貪婪 | 人性預判 |
| **第二步** | 接受了禮物就不好意思拒絕借路 | 社會心理——吃人嘴軟 |
| **第三步** | 禮物遲早會拿回來——「取之中府而藏之外府」 | 消除成本顧慮——零成本操作 |
| **第四步** | 宮之奇雖然聰明但有性格弱點，虞公不會聽他的 | 精準人物分析——「達心而懦，少長於君」 |

荀息對宮之奇的評價極其精準：「達心而懦」——心裡明白但性格懦弱；「少長於君」——從小和虞公一起長大所以虞公不把他當回事。這是全文中人類洞察力的最高表現。

### 修辭手法一覽

只列本文有辨識度的手法；引文用字從底本（如「彊諫」「脣亡」）。

| 手法 | 原文 | 效果 |
|:----|------|------|
| **反問（反詰）** | 「虞無師，其曰師，何也？」「其先晉何也？」「虞之爲主乎滅夏陽，何也？」 | 三問皆為自問自答，答案就在下一句——形式是提問，功能是逼出「爲主乎滅夏陽」的結論，等於不容置辯的斷語 |
| **比喻** | 「語曰：『脣亡則齒寒。』其斯之謂與。」 | 借一句現成諺語，以生理常識喻虞、虢的地緣相依；下一句「其斯之謂與」把比喻直接壓到兩國身上，一步到位 |
| **對偶** | 「取之中府而藏之外府、取之中廄而置之外廄」 | 中府／外府、中廄／外廄，兩個四字句字數、結構全同而只換一字；「取」與「藏」、「中」與「外」兩兩相扣——寶物「只是換個地方存放」的從容，全在這兩句的對稱裡 |
| **反諷** | 「璧則猶是也，而馬齒加長矣。」 | 不罵一句，只陳述「璧沒變、馬老了」這個事實；愈是輕描淡寫，愈顯虞公五年心血等於白費 |

此外，荀息分析宮之奇的三句——「達心則其言略，懦則不能彊諫，少長於君，則君輕之」——是**三句同構**的排比（性情＋後果），把宮之奇的三重弱點一次列盡，荀息斷人用的是清單。此處之所以稱排比而非對偶，正因句數是「三」；若只有兩句同構，依通例就該歸入對偶（如表中「取之中府」一例）。

## 3. 佳句賞析

### 「虞無師，其曰師，何也？以其先晉，不可以不言師也。其先晉何也？爲主乎滅夏陽也。」

虞國沒有出兵，經文為什麼稱之為「師」？因為它的名字排在了晉國前面——你不可能說排在前面的那支軍隊不存在。為什麼把它排在前面？因為它對滅夏陽這件事負主要責任。

這一段是穀梁傳的「法學推論」——從一個詞的順序（虞師在晉師之前）推導出倫理判斷（虞國是主犯）。表面上是語言學問題，實際上是責任歸屬問題。

### 「非國而曰滅，重夏陽也。」

夏陽不是國家，經文卻用「滅」字，因為重視夏陽。

這是穀梁傳「名實之辨」的另一半。按常理，「滅」只能用於國家；經文卻對一個城邑用「滅」字，正是要讀者追問：一個城邑何以配得上「滅」？答案緊接著揭曉——夏陽是虞、虢的塞邑，滅了它，兩國便都完了。一字之微，伏下全篇的地緣論證。

### 「語曰：『脣亡則齒寒。』其斯之謂與。」

嘴唇沒有了，牙齒就會感到寒冷——（諺語）說的正是這種情形吧。

底本作「脣亡」，今通作「唇亡」，異體字之別，義同。

這句諺語之所以千古流傳，是因為它用一個人人都能理解的生理常識，說明了地緣政治中最深刻的真理——**相鄰的國家是命運共同體**。虞公以為虢國被滅只是虢國的事，但他沒有想到：虢國是虞國的「唇」，沒有了唇的保護，虞國這副「齒」還能撐多久？值得注意的是，穀梁傳這裡只借諺語點到為止（「其斯之謂與」），不像《左傳·僖公五年》那樣把「輔車相依」的道理層層鋪開——這正是底本評語所說的「言果略」。這句諺語後來成為中文裡關於「共同命運」最經典的表達。

### 「璧則猶是也，而馬齒加長矣。」

璧還是那塊璧，馬的年齒卻長了（馬老了）。

這是全篇最鋒利的一句。荀息牽著那匹五年前送出去的馬、捧著那塊五年前送出去的璧，對人說：東西還是原來的東西——只是馬老了。語氣平靜得像在說一件日常小事，但這句話的殺傷力在於：它讓虞公五年前的貪婪和愚蠢變得無所遁形。你為了這塊璧和這匹馬出賣了國家——結果璧回來了，馬回來了，只有你的國家沒有回來。這種極其克制、極其冷靜的諷刺，比任何大聲嘲諷都要致命。

## 4. 白話改編（節要）與原文對照

改編只取主幹（經文書法之問、塞邑、獻計、料人、借道、結局六個關節），細節一概從略；引文從底本用字。

### 4.1 白話改編（節要）

《春秋》記載：「虞師、晉師滅夏陽。」穀梁傳解釋說：夏陽不是一個國家，經文卻用「滅」字——因為夏陽的得失事關重大。虞國根本沒有出兵，經文卻稱「虞師」，還把它排在晉國前面，為什麼？因為虞國對滅夏陽這件事負主要責任。

夏陽是虞、虢兩國之間的邊界要塞。拿下夏陽，兩國就等於一起被拿下了。

於是晉獻公動了伐虢的念頭。大夫荀息說：「您何不用屈地產的良馬、垂棘出的美玉，去向虞國借路呢？」獻公捨不得：「這是晉國的寶物啊。萬一虞國收了禮卻不借路，怎麼辦？」荀息說：「這是小國侍奉大國的道理：他不借路，就不敢收禮；收了禮又借了路，那不過是我們把寶物從內庫搬到外庫、從內廄牽到外廄罷了。」

獻公仍有顧慮：「宮之奇還在虞國，他一定不會讓虞君收下。」荀息說：「宮之奇這個人，心裡明白卻生性懦弱，又從小與虞君一起長大。明白，所以說話只舉綱要；懦弱，所以不能極力勸諫；從小一起長大，所以虞君輕視他。何況玩好之物就在眼前，而禍患遠在一國之後——這種事要中等智力以上的人才想得到。我料定虞君，是中等智力以下。」

獻公於是借道伐虢。宮之奇進諫：「晉國使者言辭謙卑而禮物厚重，這對虞國一定不利。」虞公不聽，收下禮物、借出道路。宮之奇再諫：「諺語說『脣亡則齒寒』，說的正是這種情形吧！」說完，帶著妻子兒女投奔曹國。

獻公亡虢（魯僖公五年），接著就攻下虞國。荀息牽著馬、捧著璧上前說：「璧還是這塊璧，馬的齒齡可就加長了。」

**— 白話改寫完 —**

| 荀息曰：「此小國之所以事大國也。彼不借吾道，必不敢受吾幣，如受吾幣，而借吾道，則是我取之中府而藏之外府、取之中廄而置之外廄也。」 | 荀息說：「這是小國用來侍奉大國的道理。他不借路給我們，就必定不敢收我們的禮物；如果收了禮物、又借了路，那不過是我們把寶物從內庫取出、藏到外庫，把馬從內廄牽出、放到外廄罷了。」 |
| 公曰：「宮之奇存焉，必不使受之也。」 | 獻公說：「宮之奇還在（虞國），他一定不會讓虞君收下。」 |
| 荀息曰：「宮之奇之爲人也，達心而懦，又少長於君。 | 荀息說：「宮之奇的為人，心裡通達卻生性懦弱，又是從小與虞君一起長大的。 |
| 達心則其言略，懦則不能彊諫，少長於君，則君輕之。 | 心裡通達，所以說話只舉綱要；生性懦弱，所以不能極力勸諫；從小與君一起長大，所以虞君輕視他。 |
| 且夫玩好在耳目之前，而患在一國之後，此中知以上乃能慮之，臣料虞君、中知以下也。」 | 況且玩好之物就在耳目之前，而禍患遠在一國之後；這種事要中等智力以上的人才能考慮到。我料定虞君是中等智力以下的。」 |
| 公遂借道而伐虢。 | 獻公於是向虞國借道，出兵討伐虢國。 |
| 宮之奇諫曰：「晉國之使者，其辭卑而幣重，必不便于虞。」 | 宮之奇進諫說：「晉國使者的言辭謙卑，禮物卻厚重，這對虞國一定沒有好處。」 |
| 虞公弗聽。遂受其幣而借之道。 | 虞公不聽。於是收下禮物，把道路借給了晉國。 |
| 宮之奇又諫曰：「語曰：『脣亡則齒寒。』其斯之謂與。」 | 宮之奇又一次進諫說：「諺語說『嘴唇沒有了，牙齒就會冷』，說的正是這種情形吧。」 |
| 挈其妻子以奔曹。 | 他帶著妻子兒女，逃奔曹國。 |
| 獻公亡虢五年，而後舉虞。 | 獻公滅掉虢國，到魯僖公五年才接著攻下虞國。 |
| 荀息牽馬操璧而前曰：「璧則猶是也，而馬齒加長矣。」 | 荀息牽著馬、捧著璧走上前說：「璧還是這塊璧，馬的齒齡卻加長了。」 |

> **注**：「公遂借道而伐虢」一句，主語是晉獻公，借道的對象是虞國——是晉向虞借道，不是虞借道給誰。底本此句省去受詞，讀時須自行補足，否則容易誤讀為「虞公借道」。
>
> **注**：「獻公亡虢五年」的「五年」，底本斷句作連讀，指魯僖公五年（見第 5 節）。底本所附白話譯本作「獻公滅了虢國五年之後，才攻下虞國」，是把「五年」講成五年之後——此說與《左傳》同年滅虞的記載不合，本頁不從。

### 5.3 「獻公亡虢五年」的斷句與時序

底本作「獻公亡虢五年，而後舉虞」——「五年」緊接「亡虢」，讀作**魯僖公五年**（前 655）。理由有三：

1. 《左傳·僖公五年》：「冬，十二月，丙子，朔，晉滅虢。虢公醜奔京師。……師還，館于虞，遂襲虞，滅之。」——**滅虢與滅虞同在僖公五年**，並非隔五年。
2. 《公羊傳·僖公二年》作「還，四年，反取虞」，同樣把第二次行動定在四年之後的僖公五年，而不是「等五年」。
3. 若解為「滅虢之後五年才滅虞」，則虞國在虢亡後仍存在五年，與《左傳》所記「師還，館于虞，遂襲虞」的同年回師襲取不合。

> **不確定處**：底本夾注本所附白話譯本逕作「獻公滅了虢國五年之後，才攻下虞國」，可見**編者或譯者本身即讀作「五年之後」**。本頁採「僖公五年」說（有《左傳》《公羊傳》雙重支持），但這是一個**有異說的讀法**，非定論。

### 5.4 用字與人物查證

- **荀息**：夾注本注「晉大夫」，作「荀息」，與《左傳·僖公二年》「晉荀息請以屈產之乘」、《公羊傳》「荀息進曰」一致。其人即**荀叔**（《漢書·地理志》顏師古注引《竹書紀年》：「（晉）武公滅荀以賜大夫原氏，是為荀叔」），名**息**（一說「息」為字），晉獻公的重要謀臣。本篇各本皆作「荀息」，無異文。
- **宮之奇**：夾注本注「虞賢大夫」，《左傳·僖公二年》亦作「宮之奇」，無異文（「宮」不作「宫」，「奇」不作「琦」）。
- **晉獻公**：本篇稱「公」，至「虞公弗聽」始明標「虞公」；夾注本注「晉君」處即指獻公。
- **地名**：「屈產之乘」之「屈」，夾注本夾注音「橘」，注云「屈地產良馬」；「垂棘之璧」注云「垂棘出美玉」。
- **篇題「虞師晉師滅夏陽」**：底本、《穀梁傳》、《公羊傳》皆作「**夏**陽」；《左傳》記同一經文作「**下**陽」（「虞師、晉師滅下陽」、「滅下陽」）——「夏」「下」形近，學者多以為古本異文或唐諱改字，非誤字，故本頁不改底本。

### 5.5 異體字說明（不視為誤字）

「爲／為」「彊／強」「脣／唇」「于／於」四組，皆屬異體或古今字之別，底本用字照錄，不擅自改動；正文引文依底本，白話與敘述文字依台灣通用字形（如「唇亡齒寒」、「強諫」）。
