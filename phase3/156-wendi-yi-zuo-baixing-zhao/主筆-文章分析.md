# 文帝議佐百姓詔 — 文章分析

> 漢文帝 劉恒
>
> 本檔案由 @Hermes Agent 主筆

## 1. 文章結構分析

〈文帝議佐百姓詔〉篇幅極短（全文僅一百九十餘字），但結構完整，層次分明——起、承、轉、合，一氣呵成。

**第一段：指出問題——「間者數年比不登」**

> 「間者數年比不登，又有水旱疾疫之災，朕甚憂之。愚而不明，未達其咎。」

詔書開門見山：近年來連續歉收，水旱瘟疫交加——我很擔憂。但緊接著文帝做了一件極不尋常的事——他對天下人說「愚而不明，未達其咎」：我愚鈍不明，不知道過錯在哪裡。皇帝公開承認自己「不知道」，在中國政治史上是極罕見的。

**第二段：自我檢討——「意者朕之政有所失而行有過與」**

> 「意者朕之政有所失而行有過與？乃天道有不順，地利或不得，人事多失和，鬼神廢不享與？何以致此？將百官之奉養或費，無用之事或多與？何其民食之寡乏也？」

文帝推想了所有可能的原因：是我的政策有問題嗎？是我的行為有過失嗎？是天道不順、地利未盡、人事失和、鬼神不享嗎？官員的俸祿供養是否過於浪費？無用之事是否太多？百姓的糧食為何如此缺乏？他從自己的施政一路排查到天地鬼神、百官庶務——沒有一個細節被放過。

**第三段：精確計算——「其咎安在？」**

> 「夫度田非益寡，而計民未加益，以口量地，其於古猶有餘，而食之甚不足者，其咎安在？」

這是全詔最精彩的一段。文帝做了一個樸素的推理：土地沒減少、人口沒大增——按人均來算，土地比古代還多——但糧食不夠吃。這說明什麼？問題不在客觀條件，而在施政方式。他問「其咎安在？」——過錯到底在哪裡？這不是問老天爺，而是問行政系統。

**第四段：開放邀請——「無有所隱」**

> 「無乃百姓之從事於末以害農者蕃，為酒醪以靡穀者多，六畜之食焉者眾與？細大之義，吾未能得其中。其與丞相、列侯、吏二千石、博士議之，有可以佐百姓者，率意遠思，無有所隱！」

文帝進一步推測具體原因——工商業過度、釀酒浪費、牲畜耗糧——但他不確定，於是下令群臣討論：「率意遠思，無有所隱」——大膽地想、長遠地看、不要隱瞞。全文以這八個字收束，氣勢鏗鏘。

> **校勘註**：本文以《古文觀止》卷六通行本為底本，與《漢書·文帝紀》所載文帝後元元年（西元前 163 年）三月詔文字全同，僅標點略異；《資治通鑑》卷十五異文（「數年不登」「奉養或廢」「吾未得其中」等）不從。全文漢字凡一百九十一字。

### 起承轉合

| 結構 | 內容 |
|:----:|------|
| 起 | 天災頻繁，百姓困苦——「朕甚憂之」 |
| 承 | 自我檢討——政策、行為、天意、人事、祭祀、百官，逐一排查 |
| 轉 | 精確計算——土地不減、人口不增，糧食為何不夠？「其咎安在？」 |
| 合 | 邀請群臣——「率意遠思，無有所隱」——一起想辦法 |

## 2. 寫作技巧分析

### 「其咎安在？」——全文的靈魂

文帝在短短不足二百字的詔書中一再追問過錯之所在——先說「愚而不明，未達其咎」，再問「何以致此？」「其咎安在？」，最後以「無有所隱」收尾。這種層層遞進的追問，形成了強烈的修辭效果：他不是在敷衍了事，而是在認真追查。

### 樸素計算——用邏輯取代藉口

「夫度田非益寡，而計民未加益，以口量地，其於古猶有餘，而食之甚不足者」——文帝用最簡單的數據推翻了「天災不可抗力」這個藉口，展現了一個理性統治者的思維方式。這種以「算賬」推動檢討的手法，在古文觀止全書中是獨一無二的。

### 修辭手法

| 手法 | 原文 | 效果 |
|:----|------|------|
| 設問（層遞追問） | 「意者朕之政有所失而行有過與？……何以致此？……其咎安在？」 | 一問緊似一問，把自我檢討層層推向深處 |
| 排比 | 「乃天道有不順，地利或不得，人事多失和，鬼神廢不享與？」 | 天、地、人、鬼四端並列，窮舉災異之由 |
| 對偶 | 「夫度田非益寡，而計民未加益」 | 句式整齊，土地與人口對舉，為下文推算張本 |
| 對比 | 「其於古猶有餘，而食之甚不足者」 | 地有餘與食不足兩相對照，矛盾自見 |
| 排比 | 「無乃百姓之從事於末以害農者蕃，為酒醪以靡穀者多，六畜之食焉者眾與？」 | 三項並舉，語氣一貫，把推測落到具體民生 |

## 3. 佳句賞析

### 「間者數年比不登，又有水旱疾疫之災，朕甚憂之。愚而不明，未達其咎。」

開篇四句定下全文基調。文帝不說官話套話，而是直截了當地告訴天下人：我很擔心，但我不知道問題在哪裡。一個皇帝公開承認自己「愚而不明」——這不是示弱，而是展示了一種比權威更可貴的品質：真誠。

### 「夫度田非益寡，而計民未加益，以口量地，其於古猶有餘，而食之甚不足者，其咎安在？」

全詔最核心的句子。文帝用常識推翻了所有藉口——土地沒少、人口沒多——問題不在客觀條件，而一定在施政方式。這是一個皇帝在用自己的邏輯推翻自己的懶政藉口，展現了清醒的自我審視能力。

### 「其與丞相、列侯、吏二千石、博士議之，有可以佐百姓者，率意遠思，無有所隱！」

全文收束句。「率意遠思，無有所隱」——大膽按你們的想法去思考，不要有任何保留。這八個字是文帝對群臣的授權：他不需要大臣揣摩上意，他需要的是真話。這是一句跨越兩千年仍然震撼人心的話。

## 4. 白話改編

近年來連續糧食歉收，加上水災、旱災、瘟疫——我非常擔憂。我愚鈍不明，不知道問題出在哪裡。

想來想去：是我的政策有失誤、行為有過錯嗎？是天道不順、地利未盡、人事失和、鬼神不享嗎？為什麼會這樣呢？還是官員的俸祿開支太浪費？無用的事情太多？百姓的糧食為何如此缺乏？

再說，土地並沒有比從前少，人口也沒有增加——按人口來算土地，甚至比古代還多——可是糧食卻不夠吃——過錯到底在哪裡？

是不是百姓從事工商而荒廢農業的人太多了？釀酒浪費的糧食太多了？牲畜吃的糧食太多了？大大小小的事理，我還沒能把握其中的要領。請丞相、列侯、二千石官員、博士們一起討論——如果有可以幫助百姓的辦法，請大膽思考、長遠規劃——不要有任何隱瞞！
