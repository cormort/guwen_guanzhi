## 一、座標定位

| 項目 | 內容 |
|------|------|
| **時間** | 魯隱公三年（約西元前720年）。本年三月周平王崩（《左傳》：「三年，春，王三月，壬戌，平王崩」；《史記》繫平王崩於其五十一年）；四月鄭人取溫之麥，秋又取成周之禾 |
| **空間** | 洛邑（東周王都）與鄭國（今河南新鄭一帶） |
| **核心事件** | 周平王與鄭莊公交換人質——王子狐質於鄭，公子忽質於周 |
| **引爆點** | 平王死後，周人「將畀虢公政」（打算把政權交給虢公），鄭人遂取麥取禾，周鄭交惡 |
| **經典文眼** | 「信不由中，質無益也。」 |

**時序校正（與舊稿不同處）**：舊稿作「周平王死，周桓王即位，欲以虢公忌父分鄭伯之政」，把三件事壓在同一時點，須分疏：

- **「王貳于虢」發生在平王生前**，是平王想分政給虢公，不是桓王；《左傳》此句下別無「桓王」字樣。
- **平王崩後**，《左傳》只說「周人將畀虢公政」——「將」是未決之辭（夾注本注：「將者，未決之辭」），是周人的打算，非桓王已下任命。
- **桓王正式用虢公為卿士，在魯隱公五年（前715年）**：《左傳·隱公五年》：「夏，虢公忌父始作卿士于周。」桓王真正「奪鄭伯政」則在魯桓公五年（前707年），即繻葛之戰那年。
- 桓王是平王之**孫**（太子洩父早卒，立其子林），非平王之子，此點舊稿無誤，惟「泄父」當作「**洩父**」。
- **交質確年，本檔標為不確定**：《左傳》將此事敘於隱公三年（平王崩年），但「鄭伯怨王→王否認→交質→王崩」的敘事順序，讀起來像是崩前之事；事件究竟是崩前數年還是同年，傳世文獻沒有明說。本檔行文一律用「魯隱公三年」繫年，不另斷定月份。

此為春秋時代第一場天子與諸侯的正面權力攤牌。地點在天下之中——洛邑與鄭之間，距離不過數百里，卻丈量出周禮崩潰的深度。

## 二、時代壓力：禮崩樂壞的開局

### 2.1 東周王室的軟骨症

西元前771年，犬戎破鎬京，周幽王死於驪山。周平王在晉、鄭、秦、衛等諸侯護送下東遷洛邑——名義上是遷都，實質上是逃跑。

東遷後的周王室，面臨三大致命傷：

1. **領土縮水**：王畿從關中千里縮為洛邑周邊數百里，實力不如大諸侯。
2. **軍事依賴**：東遷全程靠諸侯護送，此後軍隊征討也需要諸侯出兵。
3. **威信破產**：平王本人有弒父之嫌（時人傳聞他與申后聯手引繒、犬戎殺幽王；此為當時流傳之說，非定論），而周天子權威早在幽王末年已因廢嫡、二王並立而動搖。

> **史料補正——「烽火戲諸侯」不可當史實用。** 舊稿寫「幽王戲諸侯（烽火戲諸侯）已使天子信譽掃地」，這句話有兩層問題：其一，烽火戲諸侯是《史記·周本紀》的記載，但烽燧報警的制度背景與該故事本身的可靠性歷來受疑；其二，清華簡《繫年》提供了另一種敘述：幽王娶西申之女生平王，後得褒姒生伯盤，「王與伯盤逐平王，平王走西申」，幽王起師圍平王於西申，申人弗畀，繒人乃降西戎共攻幽王，幽王及伯盤乃滅。據此，幽王末年的關鍵是**廢嫡逐子**與**二王並立**（虢公翰立王子余臣為攜王），不是君王博美人一笑失信於諸侯。談周室威信崩落，宜用「廢嫡逐子、二王並立」這條線，烽火之說只能標明出處備考。

### 2.2 鄭國的特殊地位

鄭國是西周晚期分封的諸侯（宣王封其弟友於鄭，是為鄭桓公），但鄭桓公、鄭武公、鄭莊公三代在王朝任職：桓公為周幽王司徒，武公、莊公相繼為平王**卿士**（執政官），身分既是諸侯，又是天子近臣。鄭國挾此雙重身分，在東周初期迅速擴張：

- **鄭武公**：護送平王東遷有功。《史記·鄭世家》載犬戎之難殺幽王與桓公後，「鄭人共立其子滑突，是為武公」；武公東取鄶等十邑之地，立國於東方。惟東虢究竟滅於鄭武公或鄭莊公，文獻說法不一，本檔標為**不確定**。
- **鄭莊公**：在位期間平定共叔段內亂，並參與伐宋、滅許等役（《左傳》隱公十年「公會齊侯、鄭伯伐宋」、隱公十一年「公會齊侯、鄭伯伐許」——伐宋、滅許皆齊、魯、鄭聯軍，非鄭國獨力），儼然小霸

莊公以卿士身分留在洛邑執政，實際上掌握了天子朝政。他既是諸侯，又是宰相——這本身就是對周禮的挑戰：諸侯不應干預天子內政，但天子又離不開這個強有力的「下屬」。

### 2.3 人質外交的荒謬

周平王不堪鄭莊公專權，想讓虢公分權制衡。鄭莊公質問，平王矢口否認，最後用**交換人質**來自清。

這在周禮中是無法想像的：

> 天子與諸侯關係，本質上是君臣父子。父親需要交出兒子做擔保、才能證明自己沒有背叛兒子——荒謬至極。

**周鄭交質**象徵的是：天子與諸侯已經站在同一水平線上交涉。君臣之間的權力關係，變成了對等國家之間的外交契約。周禮的「天子無敵體」原則，至此徹底破產。

### 2.4 惡化的必然

人質交換並未解決問題。魯隱公三年三月，周平王駕崩（《左傳》：「三年，春，王三月，壬戌，平王崩。赴以庚戌，故書之」）；周人打算把執政之權交給虢公，取代鄭莊公。鄭莊公大怒，做了一件前所未有的事：

**派祭足率軍取周室溫地之麥，秋又取成周之禾。**

（用字提醒：底本作「**取**溫之麥」「又取成周之禾」，舊稿寫「割走」是解釋性改寫，《左傳》原文只作「取」；引原文時不宜寫成「割」。）

舊稿稱此為「春秋時代諸侯第一次武力搶劫天子領地」——**本檔查無確證，標為不確定**：《春秋》經文與《左傳》本年只記錄了取麥一事，未見「首次」之類的判斷，也沒有可據以排除更早案例的完整紀錄。可確定的是，這件事在《左傳》敘事中被寫成君臣決裂的標記：夾注本說「四月猶溫，秋則徑入成周。寫鄭莊之惡，不唯無君，直是異樣慘毒」，又說平王三月崩、祭足四月寇，「言其疾也」——從人質到武裝收割，中間只隔一個月。

至於「周桓王即位後，乾脆正式剝奪鄭莊公的卿士職位」，須分兩步：魯隱公五年（前715年）「夏，虢公忌父始作卿士于周」，是虢公分權落實；直到魯桓公五年（前707年）「王奪鄭伯政，鄭伯不朝」，桓王才正式奪去鄭莊公之政。**繻葛之戰**即發生在該年秋：桓王親率諸侯伐鄭，王師敗績。但〈周鄭交質〉只寫到取麥取禾為止，留下一個「周鄭關係已經不可逆轉」的結論。

## 三、關鍵人物

### 周平王（？—前720年）

| 面向 | 分析 |
|------|------|
| **處境** | 東周第一位天子，在位五十一年（前770—前720）；以廢太子身分賴申、繒、許、晉、鄭等外力得立，從即位第一天就是弱主 |
| **性格** | 軟弱、求和、不果斷——既不敢得罪鄭國，又想制衡鄭國 |
| **失策** | 想要分權卻不敢明說；被質問後全盤否認；用交換人質這種毫無約束力的手段來維持和平。每一步都在退讓，退到無路可退時，什麼也沒解決。 |
| **軍師評語** | 平王之病，不在無謀，而在無膽。既用鄭，又疑鄭；既疑鄭，又不敢去鄭。人質之約，不過是懦夫的自欺欺人。 |

### 周桓王（？—前697年）

| 面向 | 分析 |
|------|------|
| **處境** | 平王之孫（太子洩父早卒，立其子林）；生年不詳，即位時年歲無確證，惟史稱其年少即位、血氣方剛 |
| **性格** | 剛愎、急進、不懂權謀——見不得鄭國囂張，但沒有實力壓制 |
| **行動** | 平王崩後，周人已「將畀虢公政」；魯隱公五年（前715）虢公忌父始作卿士；魯桓公五年（前707）王奪鄭伯政、鄭伯不朝，桓王親征鄭國，於繻葛中箭而敗，王室威信掃地 |
| **軍師評語** | 桓王有恢復王室之心，無恢復王室之才。少年意氣，不知實力懸殊。引而不發是最痛苦的，但貿然出手是最愚蠢的。桓王兩者都犯了。 |

### 鄭莊公（前757—前701年）

| 面向 | 分析 |
|------|------|
| **身分** | 鄭國第三代君主，王朝卿士，春秋第一位小霸主 |
| **性格** | 深沉、剛毅、精於算計——史料中最能忍、最會抓時機的諸侯之一 |
| **策略** | 以卿士身分控制朝政，用「奉王命討不臣」的名義擴張實力，實質上是在挾天子以令諸侯（這比齊桓公早了近百年） |
| **行動** | 平王在世時施壓換人質；平王崩後派祭足取溫之麥、成周之禾；魯桓公五年（前707）繻葛之戰，鄭軍大將**祝聃**射中桓王肩（《左傳·桓公五年》：「祝聃射王中肩」），非莊公親自射王 |
| **軍師評語** | 莊公是春秋第一位懂得「實力即正義」的諸侯。他從不主動挑戰天子名義——他只挑戰天子實際權力。人質是他要的，麥禾是他取的，天子是被他的部將射傷的，但他從未口出狂言說不要天子。這才是真正可怕的政治人物。 |

## 四、寫作意圖

左丘明寫〈周鄭交質〉，用意不在記錄一次外交事件，而在揭示一個時代轉折：

### 4.1 破題——信不由中

「君子曰」的第一句：「信不由中，質無益也。」這不是旁白，而是一句審判。（舊稿稱其為「文章開頭八個字」，須更正：本篇開頭是敘事——「鄭武公、莊公爲平王卿士」；此八字在敘事結束、周鄭交惡之後，是左氏的斷辭。）左丘明在告訴讀者：**人質只是表象，信任才是本質。沒有信任，一百個王子當人質也沒用。**

### 4.2 引經為證

左丘明引用《詩經》〈采蘩〉〈采蘋〉（《國風》）與〈行葦〉〈泂酌〉（《大雅》）四篇，對比周鄭交質的墮落。這四篇詩取義皆在「不嫌薄物」：只要忠信在內，即使澗谿野草、蘋蘩水草、簡陋器具、溝渠積水，也足以祭祀鬼神、進獻王公。古代聖王靠明德忠信維繫君臣，現在的周天子卻要靠交換人質來保住表面和平。這是左丘明對時代的哀嘆：禮樂忠信已經被功利主義全面取代。

（舊稿標題作「借古諷今」，不妥：左丘明是就當時之事立論並引《詩》為證，並非借更古之事諷刺今人。改題「引經為證」。）

### 4.3 為春秋大義立基

〈周鄭交質〉是《左傳》早期的篇章之一（魯隱公三年，僅晚於〈鄭伯克段於鄢〉兩年）。左丘明要在這裡告訴讀者：**春秋之所以亂，根源在於天子自棄天下**。當天子把自己降到諸侯的層次去做交易，天下就再也不會有人把天子當天子了。

### 4.4 名句賞析

> **「信不由中，質無益也。明恕而行，要之以禮，雖無有質，誰能間之？」**

翻譯：誠信若不是出自內心，交換人質也沒有用處。以明察寬恕行事、以禮制互相約束，就算沒有質子，誰又能離間呢？

（舊稿譯「信任不是發自內心」，把「信」譯成「信任（他人）」；「信不由中」的主語是發出誠信的一方，「中」即內心，故當作「誠信若不是出自內心」。）

這是全文的命脈所在。左丘明認為：人質交換是技術手段，禮義信任才是根本。周王室和鄭國的問題從來不是人質太少，而是心已經不在一起了。

## 五、戰略貫通——此事件的歷史意義

| 層面 | 意義 |
|------|------|
| **政治象徵** | 天子與諸侯交換人質，打破了「天子至尊」的禮制底線 |
| **權力轉移** | 鄭莊公以卿士挾天子，開「挾天子以令諸侯」之先河 |
| **外交型態** | 人質外交（質子制度）從此成為春秋戰國的常態，但〈周鄭交質〉證明了其無效性 |
| **戰爭導火線** | 此事（取溫之麥、成周之禾）是周鄭決裂的起點；後續魯隱公五年虢公為卿士、魯桓公五年王奪鄭伯政，終於繻葛之戰（周桓王伐鄭，王師敗績，祝聃射王中肩） |
| **史書價值** | 左丘明以此篇表明：春秋之亂，始於天子自輕 |

## 六、一句話總結

> **當天子必須與諸侯交換人質才能維持關係時，周禮已經死了——人質換不來信任，信不由中，雖質何益？**

- 「誰能**間**之」：夾注本注去聲，作離間解。

*軍師筆記：後世讀者讀到此篇，當知所謂「質子制度」從未真正維繫過和平。無論是周鄭交質、戰國時期的各國質子，乃至後世的和親、納質，本質上都是實力不對等下的妥協方案。真正能長治久安的，從來不是人質，而是「明恕而行，要之以禮」。左丘明兩千六百年前的結論，至今未過時。*
