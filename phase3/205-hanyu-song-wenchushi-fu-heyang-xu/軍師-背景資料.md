# 〈送溫處士赴河陽軍序〉背景資料

> **軍師分析 · 古文觀止卷八 · 唐文 · 韓愈**

## 一、座標定位

| 項目 | 內容 |
|------|------|
| **出處** | 《昌黎先生集》卷二十一——韓愈詩文合集，由其門人李漢編纂；〈送溫處士赴河陽軍序〉為韓愈贈序體名篇——與〈送石處士序〉（同卷）堪稱「姊妹篇」——同一將軍——同一事件——同一主題——但基調截然不同 |
| **選集** | 《古文觀止》卷八·唐文——TOC 第139篇——韓愈入選《古文觀止》共二十四篇（卷七五篇：〈原道〉〈原毀〉〈獲麟解〉〈雜說一〉〈雜說四〉；卷八十九篇：〈師說〉〈進學解〉〈圬者王承福傳〉〈諱辯〉〈爭臣論〉〈後十九日復上宰相書〉〈後廿九日復上宰相書〉〈與于襄陽書〉〈與陳給事書〉〈應科目時與人書〉〈送孟東野序〉〈送李愿歸盤谷序〉〈送董邵南序〉〈送楊少尹序〉〈送石處士序〉〈送溫處士赴河陽軍序〉〈祭十二郎文〉〈祭鱷魚文〉〈柳子厚墓誌銘〉）——本篇與〈送石處士序〉同收卷八——「伯樂一過冀北之野，而馬群遂空」是韓愈最膾炙人口的比喻之一 |
| **體裁** | 贈序——唐代文人雅集送別時的臨別贈言——本文是韓愈為溫造寫的送別序——烏重胤先後徵召了石洪和溫造兩位洛陽名士——韓愈用一個絕妙的比喻「伯樂一過冀北之野，而馬群遂空」，把這篇送別序寫成一篇幽默的「人才抱怨文」 |
| **時代** | 中唐·元和五年（810）冬——烏重胤是年（元和五年四月縛盧從史後）拜河陽節度使——鎮河陽三月後以禮羅致石洪，未數月又羅致溫造——韓愈此時四十三歲（虛歲），時任河南令（《古文觀止》夾注：「縻，繫也。時公為河南令」）——先寫了〈送石處士序〉，又寫了這篇〈送溫處士赴河陽軍序〉——兩篇對讀，可見韓愈對同一事件處理的兩種筆法 |
| **核心命題** | 人才都被挖走了——怎麼辦？「伯樂一過冀北之野，而馬群遂空」——不是因為馬被殺光了——而是因為良馬都被伯樂挑走了——同樣的，烏重胤把石洪和溫造都請走了——洛陽的人才就空了——韓愈半開玩笑地說：這樣下去，我們這些留在洛陽的人怎麼辦？ |
| **關鍵人物** | **韓愈**（本文作者——唐代古文運動領袖——「唐宋八大家」之首——元和五年冬為河南令——在同一年裡為烏重胤徵召的兩位處士寫了兩篇送別序——一篇嚴肅、一篇幽默）、**溫造（溫處士）**（字簡輿——河內人——唐初名臣溫大雅五世孫——隱居王屋山、後隱東都——被烏重胤徵召為河陽軍幕僚——在韓愈筆下他被比作「良馬」——這是極高的讚美——溫造後果入仕——歷官御史中丞、尚書右丞、御史大夫——官至禮部尚書——卒贈尚書右僕射）、**烏重胤**（河陽節度使——文中「伯樂」——先後請走石洪和溫造——在韓愈筆下他「以禮為羅」、求賢若渴）、**石洪**（〈送石處士序〉的主角——洛陽人、隱居洛之北涯——在本文中被提及——「以石生為媒」——烏重胤的求賢是持續的過程而非一次性事件） |
| **文本重點** | 烏重胤先後徵召了洛陽的兩位名士石洪和溫造——韓愈先為石洪寫〈送石處士序〉——以「使大夫恒無變其初」為核心——告誡石洪出山後不忘初心——接著又為溫造寫這篇〈送溫處士赴河陽軍序〉——這一次沒有再用告誡的語氣——而是用「伯樂一過冀北之野，而馬群遂空」的比喻——把溫造比作良馬、烏重胤比作伯樂——然後話鋒一轉說「今皆為有力者奪之」「致私怨於盡取」——全文基調幽默自信——充滿對朋友的讚美和對烏重胤的敬意 |
| **一句話總結** | **韓愈把一則送別序寫成了幽默的「人才抱怨文」——他用「馬群遂空」的比喻，既讚美了朋友溫造是良馬，也讚美了賞識朋友的烏重胤是伯樂，還不忘調侃自己「資二生以待老，今皆為有力者奪之」——這是一篇用笑聲送行的贈序。** |

## 二、時代背景——「伯樂」與「良馬」的隱喻世界

### 2.1 烏重胤——中唐最懂人才的將軍

烏重胤在〈送石處士序〉中以「以禮為羅」的形象出現——而在這篇〈送溫處士赴河陽軍序〉中——他被韓愈提升到了「伯樂」的高度：

| 面向 | 說明 |
|------|------|
| **時代背景** | 中唐時期——藩鎮割據——節度使養士成風——河陽是洛陽的北大門——烏重胤作為河陽節度使需要大量人才治理轄區——他先後徵召了石洪和溫造兩位洛陽名士——這件事在當時是重要的文化事件——顯示了一個武將對文士的高度尊重 |
| **烏重胤其人** | 烏重胤（761—827）——字保君——本為昭義軍都知兵馬使——元和五年（810）討王承宗時，其主帥昭義節度使盧從史陰與王承宗勾結——烏重胤縛盧從史以獻——憲宗嘉其忠——擢拜河陽三城節度使——與一般藩鎮將領不同——他先後以厚禮徵召石洪、溫造兩位名士入幕——顯示求賢若渴、眼光獨到——後歷橫海、山南西道等節度使——累遷檢校司空 |
| **從「以禮為羅」到「伯樂」** | 在〈送石處士序〉中韓愈讚美烏重胤「以禮為羅」——用禮儀來網羅人才——在本文中韓愈更進一步——把他直接比作伯樂——「伯樂一過冀北之野，而馬群遂空」——這是對烏重胤最高的讚美——因為伯樂是中國文化中知人善任的最高象徵 |

> **軍師按**：烏重胤在同一年裡先後徵召了石洪和溫造——這件事本身就是一個傳奇——韓愈敏銳地捕捉到了這個事件的戲劇性——先寫一篇嚴肅的〈送石處士序〉告誡石洪「恒無變其初」——接著又寫一篇幽默的〈送溫處士赴河陽軍序〉用「馬群遂空」送別溫造——同一事件、兩種寫法——韓愈的文章功力在這裡展現得淋漓盡致。

### 2.2 溫造——被「伯樂」挑中的良馬

溫造——字簡輿——河內人——唐初名臣溫大雅五世孫——與石洪齊名——但兩人的性格和際遇有很大不同：

| 面向 | 說明 |
|------|------|
| **身份** | 溫造與石洪同為東都一帶名士——出身書香門第——是唐初名臣溫大雅的五世孫（《舊唐書》本傳載其自稱「臣五代祖大雅」）——早年隱居王屋山（今河南濟源境）——後隱居東都洛陽一帶——在洛陽士林中聲望極高 |
| **性格特徵** | 從韓愈的描寫來看——溫造是一個胸懷大志的人——他在洛陽雖然隱居——但並非與世隔絕——一直在等待一個真正懂得他的人——烏重胤的到來對他是契機——一個可以施展抱負的機會 |
| **在文中的形象** | 在韓愈筆下——溫造被比作「冀北之良馬」——良馬的特質是「千里」而不是「馴服」——溫造不是可以被隨意使喚的人——他是一匹千里馬——只有伯樂才能發現他的價值——只有烏重胤這樣的將軍才值得他出山追隨——而溫造也果然不負所望——後果入仕——歷官御史中丞、尚書右丞、山南西道節度使、御史大夫——官至禮部尚書——卒贈尚書右僕射——實現了「良馬遇伯樂」的完整傳奇 |

> **軍師按**：溫造與石洪不同——石洪是被「告誡」的對象——韓愈對他說「不要忘了你是誰」——而溫造是被「讚美」的對象——韓愈對他說「你是千里馬，烏將軍是伯樂」——同樣是送別——一個是溫柔的告誡——一個是幽默的讚美——這顯示了韓愈對兩位處士的不同評價和期待。

## 三、文本結構——從「伯樂過冀北」到「馬群遂空」

### 3.1 全文結構一覽

〈送溫處士赴河陽軍序〉結構非常清晰——採取「總—分—總」的模式——以「伯樂過冀北」的比喻貫穿全文：

| 層次 | 核心內容 | 情感基調 |
|------|---------|---------|
| **第一層：提出比喻——伯樂與冀北之野** | 開篇提出全篇核心比喻「伯樂一過冀北之野，而馬群遂空」——然後話鋒一轉說「夫冀北馬多天下，伯樂雖善知馬，安能空其群邪？」——伯樂再怎麼會選馬也不可能把冀北的馬全部挑完啊——所以「馬群遂空」不是說所有的馬都被挑走了——而是說「良馬」都被挑走了——剩下的都不是好馬了——這就是「空」的真正含義 | 輕鬆幽默——像在講一個笑話——但笑話裡有深意 |
| **第二層：對應現實——東都士大夫之冀北** | 韓愈把比喻引到現實：「東都固士大夫之冀北也」——洛之北涯石生、南涯溫生——烏公「以禮為羅，羅而致之幕下」——先請走了石洪——「未數月」又請走了溫造——正是「伯樂過冀北、馬群遂空」的翻版——洛陽人才盡入烏公幕府——韓愈說這不是洛陽沒有人——而是「良」的都被挑走了——留下的都是像我這樣的「駑馬」了 | 自嘲調侃——帶著對朋友的驕傲——「你們是良馬，我是駑馬——這下洛陽可真空了」 |
| **第三層：結語——為天下賀、致私怨於盡取** | 韓愈在最後半開玩笑地說：「愈縻於茲，不能自引去，資二生以待老；今皆為有力者奪之，其何能無介然於懷邪？」——意思是：我被職守羈絆在此，不能自行引退，原本指望靠這兩位先生養老——如今都被有權勢的人奪走了——我怎能不心中介懷？——然後託溫生帶話：「為吾以前所稱，為天下賀；以後所稱，為吾致私怨於盡取也」——既賀烏公得人、又怨人才盡取——幽默抗議「你把好的都帶走了——我們留下的人怎麼辦？」 | 狡黠溫暖——帶著朋友之間才有的親近和玩笑 |

> **軍師按**：本文的結構像一場單口相聲——先提出比喻（伯樂過冀北）——再慢慢鋪陳（冀北的馬怎麼會空？）——然後對應到現實（烏重胤請走了石洪和溫造，洛陽的人才就空了）——最後抖一個包袱（你們都走了，我們留下的人怎麼辦？）——層層遞進——節奏感和幽默感十足。

### 3.2 第一層——伯樂一過冀北之野

> 「伯樂一過冀北之野，而馬群遂空。夫冀北馬多天下，伯樂雖善知馬，安能空其群邪？解之者曰：吾所謂空，非無馬也，無良馬也。伯樂知馬，遇其良，輒取之，群無留良焉。苟無良，雖謂無馬，不為虛語矣。」

— 翻譯：伯樂一次經過冀北的原野之後——馬群就空了——但是冀北的馬是天下最多的——伯樂雖然善於識馬——怎麼可能把馬群全部弄空呢？——解釋這個問題的人說——我所說的「空」不是沒有馬——而是沒有好馬——伯樂知道什麼是好馬——遇到好馬就把它挑走——馬群裡就沒有留下好馬了——如果沒有好馬——即使說「沒有馬」——也不算假話了。

| 句子 | 翻譯 | 策略分析 |
|------|------|---------|
| **「伯樂一過冀北之野，而馬群遂空」** | 伯樂一次經過冀北的原野之後，馬群就空了 | 開門見山——一個爆炸性的句子——短短十三個字就建立了全文的核心隱喻——也為後面的自嘲和幽默打下了基礎——這個句子的力量在於它的「不合理」——伯樂是來選好馬的——怎麼會反而讓馬群空了？——這引起了讀者的好奇——也讓韓愈有了解釋的空間 |
| **「夫冀北馬多天下，伯樂雖善知馬，安能空其群邪？」** | 冀北的馬是天下最多的，伯樂雖然善於識馬，怎麼可能讓馬群全空了呢？ | 這是一個「反問」（反詰）——答案自在問中：不可能——韓愈故意提出這個不可能的問題——來引發思考——問題的答案就是全文的關鍵——「空」不是真的空——而是「沒有好馬了」 |
| **「解之者曰：吾所謂空，非無馬也，無良馬也」** | 解釋的人說：我所說的空，不是沒有馬，而是沒有好馬 | 韓愈用「解之者」的口吻來回答前面的問題——這是非常巧妙的敘述策略——沒有直接說「我認為」——而是假託「有人解釋」——讓解釋顯得更客觀、更有說服力——「非無馬也，無良馬也」是全篇的關鍵——也是韓愈真正想說的話 |

> **軍師按**：開篇用「伯樂一過冀北之野，而馬群遂空」十三個字就建立了一個永恆的文學意象——這個比喻同時做了三件事——第一讚美了溫造（良馬）——第二讚美了烏重胤（伯樂）——第三為韓愈自己的「自嘲」（駑馬）留下了空間——一個比喻三層含義——這就是韓愈的功力。

### 3.3 第二層——從冀北到東都

> 「東都固士大夫之冀北也。恃才能深藏而不市者，洛之北涯曰石生，其南涯曰溫生。大夫烏公以鈇鉞鎮河陽之三月，以石生為才，以禮為羅，羅而致之幕下。未數月也，以溫生為才，於是以石生為媒，以禮為羅，又羅而致之幕下。東都雖信多才士，朝取一人焉，拔其尤，暮取一人焉，拔其尤：自居守河南尹以及百司之執事，與吾輩二縣之大夫，政有所不通，事有所可疑，奚所諮而處焉？士大夫之去位而巷處者，誰與嬉遊？小子後生，於何考德而問業焉？縉紳之東西行過是都者，無所禮於其廬。若是而稱曰：大夫烏公一鎮河陽，而東都處士之廬無人焉，豈不可也？夫南面而聽天下，其所託重而恃力者，惟相與將耳。相為天子得人於朝廷，將為天子得文武士於幕下，求內外無治，不可得也。」

— 翻譯：東都本來就是士大夫們的冀北——依恃才能而深藏不露、不肯出賣自己的人——洛水北岸有個石生——南岸有個溫生——大夫烏公憑著斧鉞鎮守河陽三個月——認為石生有才——用禮節作羅網——把他羅致到幕府之下——不到幾個月——又認為溫生有才——於是以石生為媒介——再用禮節作羅網——又把他羅致到幕府之下——東都雖然確實多有才士——早上取一人，拔取其中最優秀的——晚上取一人，拔取其中最優秀的——從東都留守、河南尹以及各部門的執事——和我們兩縣的長官——政事有不通的——事情有可疑的——到哪裡去諮詢請教呢？——士大夫辭官閒居巷裡的——和誰交遊？——後生小子們——到哪裡去考究德行、請教學業呢？——縉紳之士往來經過這座都城的——沒有地方到他們的居所行禮——像這樣而說：大夫烏公一鎮守河陽——東都處士的居所就沒有主人了——難道不可以嗎？——那面南而治天下的天子——他所託付重任、倚靠力量的——只有宰相和將軍罷了——宰相替天子在朝廷得到人才——將軍替天子在幕府得到文武之士——這樣還要求朝廷內外治理不好——是不可能的。

| 句子 | 分析 |
|------|------|
| **「東都固士大夫之冀北也」** | 這一句是從比喻過渡到現實的關鍵——「固」字用得極好——東都本就是士大夫的冀北——冀北產良馬、東都產良士——比喻與現實無縫銜接——把溫造比作良馬、烏重胤比作伯樂、東都比作冀北之野 |
| **「以石生為才，以禮為羅，羅而致之幕下」「以溫生為才……又羅而致之幕下」** | 「以禮為羅」四字是烏公招賢的總寫照——羅、羅——兩個「羅」字連用——「為羅」「為媒」字法新奇——先致石生——「未數月」又致溫生——以石生為媒——可見烏公求賢之勤、得人先後有序 |
| **「朝取一人焉，拔其尤；暮取一人焉，拔其尤」** | 寫烏公取士之精——朝取暮取、拔其尤——呼應上文「遇其良，輒取之」——「尤」者、最優秀者——朝暮之間連拔兩「尤」——人才盡入幕府 |
| **「若是而稱曰：大夫烏公一鎮河陽，而東都處士之廬無人焉，豈不可也？」** | 這是對開篇「伯樂過冀北而馬群遂空」的直接對應——冀北變成東都、馬群變成處士之廬——若真如此說——烏公就是東都士林的伯樂——應首句之意——結構上完成閉合 |

> **軍師按**：從「冀北」到「東都」——從「馬群」到「人才」——韓愈的比喻不是隨便用的——而是有嚴密的邏輯結構——先提出一個看似不合理的命題（伯樂過冀北、馬群就空了）——然後解釋（不是真空、是沒有好馬了）——然後對應到現實（烏重胤請走了石洪和溫造、東都人才就空了）——每一步都嚴絲合縫——這就是韓愈作為文章大師的邏輯功力。

### 3.4 第三層——為天下賀、致私怨於盡取

> 「愈縻於茲，不能自引去，資二生以待老；今皆為有力者奪之，其何能無介然於懷邪？生既至，拜公於軍門，其為吾以前所稱，為天下賀；以後所稱，為吾致私怨於盡取也。留守相公首為四韻詩歌其事，愈因推其意而序之。」

— 翻譯：我被羈絆在這裡——不能自行引退——原本依靠這兩位先生來養老——如今都被有權勢的人奪走了——我怎能不心中介懷呢？——溫生到達之後——在軍門拜見烏公——請替我把我前面所稱道的——為天下道賀——把我後面所稱道的——替我表達對人才被盡數取走的私怨——留守相公首先作了四韻詩歌詠這件事——我因而推演他的心意寫了這篇序。

| 句子 | 分析 |
|------|------|
| **「愈縻於茲，不能自引去，資二生以待老」** | 自述身分與私情——「縻」即羈絆——韓愈時為河南令、縻於職守——不能像二生一樣引去——原本指望靠這兩位賢士養老——這是以退為進——越說自己離不開——越顯二生之賢 |
| **「今皆為有力者奪之，其何能無介然於懷邪？」** | 全篇最幽默的一句——把烏公徵賢說成「奪」——把賢士比作被奪走的財產——「介然於懷」即心中不快——明明要送行——卻說「我心裡不舒服」——這種「反筆」正是韓愈的幽默——本以致頌、反更生怨——絕妙文情 |
| **「其為吾以前所稱，為天下賀；以後所稱，為吾致私怨於盡取也」** | 全文收束之筆——「以前所稱」指「求內外無治不可得也」——為天下得人——故為天下賀——「以後所稱」指「介然於懷」——人才盡去——故致私怨於盡取——一賀一怨——對偶收結——直挽篇首「空」字——收盡通章 |
| **「留守相公首為四韻詩歌其事，愈因推其意而序之」** | 交代作序緣由——東都留守相公首先作四韻詩詠此事——韓愈推演其意而作此序——點明本文乃唱和推演之作——謙抑收筆 |

> **軍師按**：本文的結尾是中國文學史上最溫馨的「抱怨」之一——韓愈用自嘲的方式說「你們都走了，我們留下的人怎麼辦？」——但每個人都知道他其實是在為朋友高興——「你去吧，找到了好歸宿，我真的為你開心——只是捨不得你罷了」——這種「笑著說再見」的語氣——讓這篇贈序充滿了溫暖的人情味。

## 四、關鍵人物

### 4.1 溫造——被韓愈讚為「良馬」的處士

| 項目 | 內容 |
|------|------|
| **身份** | 字簡輿——河內人——唐初名臣溫大雅五世孫（《舊唐書》本傳載其自稱「臣五代祖大雅」——非溫彥博後裔——溫彥博為大雅之弟——溫庭筠方為彥博裔孫）——早年隱居王屋山、後隱東都——與石洪齊名——被烏重胤徵召為河陽節度使幕僚——在本文中被比喻為「良馬」 |
| **性格特徵** | 從韓愈的筆法來看——溫造胸懷大志——隱居而並非消極避世——一直在等待適當的契機——烏重胤的到來就是那個契機——他的出山是主動的選擇 |
| **後果入仕** | 溫造出山後果然一展抱負——長慶初為京兆府司錄參軍——奉使河朔稱旨——歷殿中侍御史、起居舍人、御史中丞——大和中遷尚書右丞——出為山南西道節度使（興元平亂、立斬殺李絳之叛卒千人）——入為兵部侍郎——歷東都留守、河陽節度使——再入為御史大夫——大和九年（835）五月改禮部尚書——六月病卒——年七十——贈尚書右僕射——「良馬遇伯樂」的完整傳奇 |
| **與石洪的對比** | 石洪在〈送石處士序〉中是被「告誡」的對象——韓愈對他的期許是「恒無變其初」——而溫造在本文中是被「讚美」的對象——韓愈對他的態度是幽默而熱情的——石洪隱居多年需要被提醒不忘初心——溫造則更果斷——所以韓愈的語氣更輕鬆親切 |

**軍師評**：溫造在韓愈筆下是一個「被祝福」的人——他的出山被賦予了「良馬遇伯樂」的光環——韓愈沒有對他說「不要忘了你是誰」——而是說「你是好馬，去吧，烏將軍是真正懂得你的人」——這種語氣的差異——讓本文比〈送石處士序〉多了一層輕鬆和溫暖——而溫造其後的仕途（官至禮部尚書、贈尚書右僕射）也證明韓愈沒有看錯人。

### 4.2 烏重胤——從「以禮為羅」到「伯樂」

| 項目 | 內容 |
|------|------|
| **身份** | 河陽三城節度使——中唐名將——在〈送石處士序〉中是「以禮為羅」的將軍——在本文中是「伯樂」——兩篇合讀——可見韓愈對烏重胤的評價從「以禮待士」提升到「知人之明」的高度 |
| **從「以石生為媒」到「又羅而致之幕下」** | 烏重胤先後徵召了石洪和溫造——不僅顯示求賢若渴——也顯示影響力——能接連請到兩位洛陽最負盛名的處士——在當時是轟動的事——韓愈敏銳地捕捉到這個事件的意義——用「伯樂過冀北」來比喻烏重胤的兩次徵召 |
| **在文中的角色** | 烏重胤在文中沒有直接出場——但是整篇文章的隱形主角——「伯樂」的比喻就是為他而設的——「大夫烏公一鎮河陽，而東都處士之廬無人焉」——直接把他和伯樂劃上等號——這是對烏重胤最高的讚美 |

**軍師評**：烏重胤在這兩篇序中的形象是層層遞進的——在〈送石處士序〉中是「以禮為羅」的將軍——在本文中是「伯樂」——韓愈用兩篇序完成了對烏重胤從「禮賢下士」到「知人善任」的完整讚美——這是韓愈對烏重胤最美好的致敬。

### 4.3 韓愈——幽默送別中的可愛主角

| 項目 | 內容 |
|------|------|
| **寫作時的處境** | 韓愈（768—824）——此時四十三歲（虛歲）——時任河南令（東都洛陽）——他在官場中歷經起伏——對「人才被挖走」這個現象有很深的體會——因為他自己就是官員與文人之間不斷被爭取的對象——所以寫這篇序時帶有一種過來人的從容和幽默 |
| **在文中的角色** | 韓愈在文中是「自嘲者」——他把二生比作良馬、把自己比作被留下的「駑馬」——「愈縻於茲，不能自引去」——「資二生以待老」而今「皆為有力者奪之」——既是謙虛也是幽默——用貶低自己的方式成就朋友的形象——這是極其高級的送別藝術 |
| **與〈送石處士序〉的對比** | 在〈送石處士序〉中韓愈是「告誡者」——對石洪說「恒無變其初」——在本文中韓愈是「幽默送行者」——對溫造說「你是良馬，去吧，我們留下的人會想念你」——兩篇序展現了韓愈作為朋友的兩面——嚴肅的一面和溫暖的一面 |

**軍師評**：韓愈在本文中做了一件非常可愛的事——沒有板著臉說大道理——而是和朋友開了一個玩笑——「你是好馬，我是駑馬，你走了我怎麼辦？」——這種自嘲式的幽默讓這篇贈序變得無比親切——也讓我們看到韓愈在嚴肅的古文大家之外的另一面——一個會開玩笑、會自嘲、會和朋友說「捨不得你」的溫暖的人。

## 五、核心分析——「馬群遂空」的比喻藝術

### 5.1 為什麼「伯樂過冀北」是一個絕妙的比喻？

韓愈選擇「伯樂過冀北」這個比喻不是偶然的——它同時完成了三項功能：

第一——**讚美了溫造**——把溫造比作「良馬」是極高的讚美——因為在中國文化中「良馬」不僅代表才能、更代表品德——「千里馬」需要伯樂才能被發現——這暗示溫造是有真才實學但不輕易出山的人——只有烏重胤這樣的「伯樂」才能讓他願意出山。

第二——**讚美了烏重胤**——把烏重胤比作「伯樂」是對他知人之明的最高肯定——伯樂在中國文化中是「知音」的象徵——韓愈說烏重胤就是伯樂——因為他懂得溫造的價值——他看得出誰是真正的人才。

第三——**為自嘲留下了空間**——「馬群遂空」這個說法本身就帶有幽默色彩——因為「空」不是真的空——而是「沒有好馬了」——韓愈順著這個邏輯說「我就是那個留下的不良之馬」——既謙虛又幽默——讓整篇文章充滿了輕鬆的氛圍。

### 5.2 這篇贈序的基調——笑著說再見

本文與〈送石處士序〉最大的不同在於基調——〈送石處士序〉的基調是莊重的——「使大夫恒無變其初」——帶著告誡和期許的分量——而本文的基調是幽默的——韓愈從頭到尾都在開玩笑——「伯樂過冀北，馬群遂空」的比喻、烏公鎮河陽而東都處士之廬無人、「愈縻於茲」卻「資二生以待老」而二生盡被「奪」走——這些話沒有一句是真正的抱怨——每一句都是帶著笑的祝福。

為什麼同一個事件（烏重胤徵召處士）韓愈會用兩種完全不同的基調來寫？——可能的原因是石洪和溫造的性格不同——石洪隱居多年，韓愈覺得需要對他說一些嚴肅的話、讓他不要忘了初心——而溫造更年輕更自信，韓愈覺得不必再說大道理——用幽默來送別反而更適合。

### 5.3 「馬群遂空」——一個永遠的文學意象

「伯樂一過冀北之野，而馬群遂空」這十三個字在中國文學史上留下了深遠的影響——後世文人在形容人才流失時常常引用這個比喻——它的力量在於把一個抽象的現象（人才被挖走）轉化為一個具體的畫面（伯樂走過原野、馬群就空了）——而且這個畫面本身帶有一種「誇張」的喜感——冀北馬多天下——伯樂怎麼可能全部挑完？——但如果挑走的都是良馬——那剩下的就真的和沒有一樣了——這種「誇張中帶著合理」的手法正是韓愈最擅長的修辭技巧。

## 六、軍師核心分析——「笑著送別」的藝術

### 6.1 這篇贈序不是告誡——是祝福

本文讀到最後你會發現——它的核心不是說教、不是告誡——而是祝福——韓愈沒有對溫造說「你要記得什麼」——沒有說「你不要忘了什麼」——他只是說「你是良馬，你遇到了伯樂，去吧」。

這與〈送石處士序〉形成鮮明對比——〈送石處士序〉是「向前看」的——「出了山以後你要小心」——而本文是「向後看」的——「你走了，我們留下的人會想念你」——一個是對未來的期許——一個是對當下的珍惜——兩篇放在一起讀——可以看到韓愈對「送別」這件事的完整理解——既要對朋友的未來負責——也要對朋友的當下溫柔。

### 6.2 為什麼要用幽默來送別？

韓愈選擇用幽默來送別溫造可能有幾個原因：

第一——**溫造的性格**——溫造比較自信和果斷——韓愈覺得不需要對他說大道理——用幽默反而更能讓他感受到朋友的溫暖。

第二——**送別的場合**——這次送別可能是在比較輕鬆的場合——不像送石洪時那樣正式——可能就是幾位朋友小聚——韓愈順手寫了這篇序——語氣自然就輕鬆了。

第三——**韓愈的文學策略**——韓愈已經寫了一篇嚴肅的〈送石處士序〉——如果再用同樣的語氣寫這篇就會重複——他想給讀者一個不一樣的閱讀體驗——所以換了一個調子——讓兩篇序形成互補——一個嚴肅、一個輕鬆——一個告誡、一個祝福。

### 6.3 「伯樂一過冀北之野」——一句話的永恆力量

「伯樂一過冀北之野，而馬群遂空」這十三個字是中國文學史上最經典的比喻之一——它的力量來自三個層面：

第一——**畫面感**——「伯樂走過原野、馬群就空了」——這是一個畫面感極強的句子——讀者彷彿可以看到那個畫面——伯樂策馬而過——身後的馬群漸漸稀疏——最後空了。

第二——**合理性**——「冀北馬多天下」——但伯樂挑走的都是良馬——所以「馬群遂空」不是沒有馬——而是沒有好馬了——這個解釋讓誇張的比喻變得合理——也有了說服力。

第三——**多義性**——這個比喻可以同時讚美三個人——讚美溫造（良馬）——讚美烏重胤（伯樂）——也讓韓愈自己可以自嘲（不良之馬）——一個比喻三層意義——這就是韓愈作為文章大師的語言功力。

## 七、一句話總結（再錄）

> **韓愈把一則送別序寫成了幽默的「人才抱怨文」——他用「馬群遂空」的比喻，既讚美了朋友溫造是良馬，也讚美了賞識朋友的烏重胤是伯樂，還不忘調侃自己「資二生以待老，今皆為有力者奪之」——這是一篇用笑聲送行的贈序。**

> **「伯樂一過冀北之野，而馬群遂空」——這十三個字——是韓愈送給溫造最高的讚美——也是韓愈送給溫造最溫暖的玩笑——「你是良馬，烏將軍是伯樂——你們是天生一對——去吧——不要擔心——我們這些留下的人雖然會想念你——但是我們真的為你高興」。**

> **而在更深的層次上——這篇序寫的是「知音」的力量——烏重胤是溫造的知音——韓愈是烏重胤和溫造的知音——他看得懂烏重胤為什麼要請溫造——也看得懂溫造為什麼願意去——他用一個幽默的比喻把這份「知音」之情寫得淋漓盡致——讓這篇序成為了中國文學史上最溫暖的送別文之一。**

- 《昌黎先生集》卷二十一〈送溫處士赴河陽軍序〉（韓愈）——本篇原文——是理解韓愈贈序體及「幽默送別」藝術的第一手文本
- 《昌黎先生集》卷二十一〈送石處士序〉（韓愈）——本篇的姊妹篇——韓愈同年（元和五年）為另一位被烏重胤徵召的處士石洪寫的送別序——與本篇堪稱「雙璧」——一篇告誡、一篇祝福——同一將軍、同一事件、同一主題——對讀可以看到韓愈對「處士出山」這個現象的完整思考
- 《古文觀止》卷八（吳楚材、吳調侯編）——〈送石處士序〉與〈送溫處士赴河陽軍序〉在《古文觀止》中的原文及夾注——可以由此連結兩篇進行對照閱讀
- 《舊唐書·溫造傳》《新唐書·溫造傳》——溫造的傳記——可以了解這位被韓愈比作「良馬」的處士其後入仕的完整仕途
- 《舊唐書·烏重胤傳》《新唐書·烏重胤傳》——烏重胤的傳記——可以了解這位被韓愈比作「伯樂」的將軍的生平與事蹟

### 8.3 現代延伸

- 余英時《士與中國文化》——余英時論述中國知識分子的演變——其中對「仕」與「隱」的討論可以與韓愈的兩篇送處士序對照閱讀——理解「處士出山」這個現象的深層文化意義
- 錢鍾書《管錐編》——錢鍾書對韓愈文章中的比喻藝術有精闢的分析——尤其是「伯樂與良馬」這個原型比喻在中國文學中的演變——可以作為理解本篇比喻藝術的參考

## 九、背景補遺

### 9.1 「伯樂」典故的來源

「伯樂」是中國文化中「知音」和「知人善任」的最高象徵——伯樂相傳姓孫名陽、春秋時人、以善於相馬聞名——典故見於《莊子·馬蹄》（「我善治馬」）、《戰國策·楚策四》（汗明說春申君：「驥服鹽車而上太行，伯樂遭之，下車攀而哭之」——驥遇伯樂而鳴）——而「伯樂一顧、價增十倍」的典故則出《戰國策·燕策二·蘇代為燕說齊》：「人有賣駿馬者，比三旦立市，人莫之知。往見伯樂曰：『願子還而視之，去而顧之。』伯樂乃還而視之，去而顧之，一旦而馬價十倍。」——韓愈在本文中借用這個典故——把烏重胤比作伯樂、把溫造比作良馬——而且不止於「相馬」——更創造了「伯樂過冀北而馬群遂空」這個全新的意象——讓古老的典故煥發了新的生命力。

### 9.2 唐代幕府制度與「雙重徵召」

唐代節度使擁有開府辟署幕僚的權力——可以自行聘請人才擔任幕職——烏重胤在同一年裡先後徵召了石洪和溫造——這在當時是轟動的事——一位節度使能接連請到兩位洛陽最負盛名的處士——顯示了他的影響力和誠意——韓愈為這兩位處士各寫了一篇送別序——從不同的角度記錄了這個事件——這在中國文學史上也是一個罕見的案例——同一事件兩篇名作——一篇嚴肅、一篇幽默——同樣流傳千古。

### 9.3 「馬群遂空」——這句話後來怎麼樣了？

「伯樂一過冀北之野，而馬群遂空」這句話成為了中國文學史上最經典的比喻之一——後世文人在形容人才流失時常常引用這個典故——這個比喻的生命力在於它把一個可能充滿遺憾和負面情緒的現象（人才流失）轉化為一個帶有幽默和驕傲的表達——「我們這裡的人才被挑走了——這說明我們這裡有人才——說明挑走他們的人是伯樂」——這種「正面的遺憾」正是韓愈最擅長的情感表達方式。

### 9.4 姊妹篇對讀——「告誡」與「祝福」的藝術

〈送石處士序〉和〈送溫處士赴河陽軍序〉是中國文學史上最經典的「姊妹篇」之一——它們寫於同一年（元和五年、810年）——寫給同一位將軍（烏重胤）徵召的兩位處士（石洪和溫造）——主題相同——但寫法完全不同：

| 面向 | 〈送石處士序〉 | 〈送溫處士赴河陽軍序〉 |
|------|---------------|---------------------|
| **基調** | 莊重——嚴肅——帶著告誡的分量 | 輕鬆——幽默——帶著玩笑的溫暖 |
| **核心比喻** | 「以禮為羅」——用禮儀來網羅人才 | 「伯樂過冀北——馬群遂空」——良馬被挑走 |
| **韓愈的角色** | 告誡者——「使大夫恒無變其初」 | 自嘲者——「愈縻於茲，資二生以待老」 |
| **情感核心** | 對未來的期許——「出了山不要變」 | 對當下的珍惜——「你走了我們會想你」 |
| **情緒** | 溫柔的擔憂 | 溫暖的祝福 |

這兩篇序放在一起讀——讓我們看到了韓愈作為朋友的完整形象——他既會嚴肅地對朋友說「要記得你是誰」——也會幽默地對朋友說「你走了我們會想念你」——這就是真正的友情——既有嚴肅的期許——也有溫暖的玩笑。

## 十、軍師總結

### 10.1 這篇序在韓愈作品中的位置

〈送溫處士赴河陽軍序〉在韓愈的贈序中是最特別的一篇之一——因為它是韓愈少數以幽默為基調的贈序——韓愈的贈序通常都帶有說理和告誡的成分——但這篇幾乎完全是在開玩笑——從開頭的「伯樂過冀北」到結尾的「致私怨於盡取」——每一句話都帶著笑意。

這可能是因為韓愈在寫了〈送石處士序〉之後覺得應該換一個調子來寫溫造——或者是因為韓愈和溫造的關係比較親近——可以這樣開玩笑——不論原因如何——這篇序讓我們看到了韓愈在嚴肅古板的「古文大家」形象之外的另一面——一個會自嘲、會幽默、會用笑聲來送別朋友的溫暖的人。

### 10.2 一句話送給溫造

「其為吾以前所稱，為天下賀；以後所稱，為吾致私怨於盡取也。」

韓愈對溫造說了許多話——但最核心的一句其實是——「你是良馬，而烏將軍是伯樂——你們會好好相處的——去吧」。

---

> **「伯樂一過冀北之野，而馬群遂空」——這十三個字——是韓愈寫給溫造最高的讚美——也是韓愈寫給自己最溫暖的自嘲——「你們是良馬、你們找到了伯樂——而我雖然是不良之馬——但我真的為你們高興」——這就是中國文學史上最不捨也最溫暖的一句「再見」。**
